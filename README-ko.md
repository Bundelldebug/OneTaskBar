# One TaskBar

Windows 작업표시줄을 대체하는 독·런처·빠른 설정입니다. Windows 폰트와 설치된 앱의 원래 아이콘을 사용합니다. [English](README.md)

## 설치

[최신 릴리스](https://github.com/Bundelldebug/OneTaskBar/releases/latest)에서 **OneTaskBar-Setup.exe**를 받아 실행하고 설치를 누르세요. 자동 실행·바탕 화면 바로가기·설치 후 실행을 선택할 수 있습니다. 기본 설치와 사용에 관리자 권한이 필요하지 않으며 인증서 신뢰나 Windows 보안 정책을 바꾸지 않습니다.

- 실제 검증 환경: Windows 11 x64. Windows 10 2004 이상 x64와 .NET Framework 4.8도 호환 대상으로 삼지만 모든 Windows 빌드에서 셸 연동을 검증한 것은 아닙니다.
- 초기 배포 파일에는 코드 서명이 없습니다. Windows에서 알 수 없는 게시자 또는 SmartScreen 안내가 나올 수 있습니다. 릴리스의 SHA256SUMS로 파일을 확인할 수 있습니다.
- 프로그램: `%LOCALAPPDATA%\OneTaskBar\App`
- 설정: `%LOCALAPPDATA%\OneTaskBar\Data`
- 제거: Windows 설정 → 앱 → One TaskBar. 프로그램을 종료하면 Windows 작업표시줄이 복원되며, 제거해도 사용자 설정은 보관합니다.
- 기존 개인용 One UI 홈의 설정이 있으면 필요한 설정 파일만 한 번 가져옵니다. APK나 기존 로고는 가져오지 않습니다.

## 동작

설정에서 빠른 설정·알림센터·키보드 시작 키·검색을 각각 Windows 기본 화면 또는 One TaskBar 화면으로 고를 수 있습니다. 앱 화면에서 바로 입력하면 검색으로 넘어가며 한글 조합 중에는 기다립니다. 터치 스크롤과 트랙패드의 미세 스크롤을 지원합니다.

독의 시작 버튼은 검색·고정 앱·최근 파일·사용자 폴더·설정·전원 메뉴를 갖춘 One UI 시작 화면을 엽니다. ‘모든 앱’을 누르면 기존 앱 화면으로 이동합니다. 시작 화면 고정과 독 고정은 별도로 저장되며, 앱 우클릭 메뉴에서 각각 고정·해제할 수 있습니다. 시작 앱은 드래그로 순서를 바꿀 수 있고, 주변 앱이 자리를 비켜 주는 애니메이션과 함께 독과 별도로 순서를 저장합니다. 시작 화면은 최대 640 × 620 DIP이며 빠른 설정과 같은 블러를 사용합니다. Windows 시작 키의 기존 선택은 유지합니다. One UI 시작 키 모드에서는 단독 Windows 키를 누르는 순간부터 셸에 전달하지 않아 기본 메뉴의 어두워짐 효과를 막고, 조합 키는 정상 순서로 전달합니다.

빠른 설정에는 실제 음량·지원되는 화면의 밝기·Wi-Fi·블루투스·음악 재생·전원 모드 등이 연결됩니다. 지원하지 않는 장치나 설치되지 않은 삼성 앱 버튼은 자연스럽게 숨깁니다. 배터리가 없는 PC에서는 배터리 부분을 숨기거나 직접 입력한 1~9999 W를 표시할 수 있습니다. 이 숫자는 실시간 전력 측정값이 아닙니다.

빠른 설정의 기능 영역은 음소거·다크 모드·방해 금지·전력 절약·화면 유지·Wi-Fi·블루투스·독 애니메이션·자동 실행을 실제 상태와 연결합니다. 전력 절약은 Windows 성능 모드를 변경하며, 화면 유지는 앱 실행 중 자동 화면 꺼짐을 막습니다. 직접 절전을 선택하는 동작은 막지 않습니다. 빠른 설정·연결 세부 메뉴·알림·앱·검색은 같은 회색 동적 블러를 사용하며, 앱과 검색창 크기는 최대 720 × 680 DIP입니다.

왼쪽 아래 Now bar는 Windows의 재생 중이거나 일시 정지된 미디어를 표시합니다. 높이 44 DIP의 캡슐이 제목 길이에 맞춰 오른쪽 상태 캡슐의 너비(최대 282 DIP)까지 늘어나고, 썸네일과 제목은 짧은 제목에서도 왼쪽에 정렬됩니다. 긴 제목은 스크롤됩니다. 누르면 재생·이전·다음·재생 위치 컨트롤로 펼쳐집니다. 미디어 앱이 제공하는 기능만 활성화하며, 썸네일의 대표색을 배경에 반영하고 흰 글자의 가독성을 위해 밝기를 조정합니다. 공간이 부족하면 기존 앱을 옮기지 않고 독 위에 배치합니다.

기본 설치는 **Windows 알림센터**를 사용합니다. 앱 설정 → Windows 알림 연결에서 자체 알림센터 연결을 진행할 수 있습니다. 선택적 로컬 패키지 등록 시 Windows가 관리자 승인을 한 번 요구할 수 있으며, 알림 접근 권한은 Windows 확인창에서 직접 허용해야 합니다. 연결 후 일반 실행·로그인에서도 등록된 ID를 다시 사용합니다. 이 연결용 패키지는 **미서명 로컬 테스트 ID**이며 배포용 코드 서명 패키지는 아닙니다. 설치기가 자동 등록하거나 보안 정책을 바꾸지는 않습니다. [알림 연결 안내와 제한](docs/NOTIFICATIONS.md)을 확인하세요.

알림 연결 후 ‘One UI 알림 팝업’을 켜면 지원되는 Windows 배너를 둥근 블러 카드로 표시합니다. 실제 Windows 배너 내용과 새 알림을 대조해 기록 전용 알림이나 이전 알림을 다시 띄우지 않습니다. 최대 3개까지 표시하며 키보드 포커스를 빼앗지 않습니다. 팝업을 닫아도 알림 기록은 남고, 표시 중인 카드가 없으면 만료 타이머도 멈춥니다.

알림을 누르면 원래 Windows 알림 카드의 동작을 우선 사용합니다. 프로토콜·등록된 알림 콜백도 활용하며, 필요한 경우 Windows 알림 기록에서 앱·제목·본문이 일치하는 카드를 찾아 실행합니다. 대응하는 항목이 없거나 중복되어 구분할 수 없으면 앱만 임의로 여는 대신 Windows 알림센터에서 확인할 수 있도록 합니다.

## 단축키와 복구

| 단축키 | 기능 |
| --- | --- |
| Ctrl+Alt+H | One TaskBar 설정 |
| Ctrl+Alt+Q | 빠른 설정 |
| Ctrl+Shift+Tab+1 | **One TaskBar 자체를 강제 종료**하고 Windows 작업표시줄 복원 |

긴급 종료는 설정에서 끌 수 있습니다. 독립 복구 도우미가 감시하므로 UI가 응답하지 않아도 사용할 수 있습니다. 현재 사용 중인 다른 앱을 종료하는 기능은 아닙니다. Windows 보안 화면이나 도우미 자체까지 종료된 상황에서는 단축키를 처리할 수 없습니다.

## 빌드와 공개 자료

Windows PowerShell에서 `Build.ps1`, 이어서 `tools/BuildInstaller.ps1 -SkipBuild`를 실행하면 앱과 설치기를 만듭니다. NuGet이나 별도 SDK 다운로드가 필요하지 않습니다. 전체 빌드·검증 방법은 [README](README.md), 측정 결과는 [VALIDATION.md](VALIDATION.md)를 참고하세요.

원본 아이콘과 소스는 MIT 라이선스입니다. Samsung APK·추출 로고·배경화면·폰트·개인 스크린샷과 영상은 배포하지 않습니다. 설치된 다른 앱의 로고는 실행 중 해당 PC에서 읽으며 권리는 각 소유자에게 있습니다. Microsoft·Samsung과 무관한 독립 프로젝트이고, 제3자의 권리 주장 가능성이 전혀 없다고 보증하는 것은 아닙니다.

## 8.5.2

- 검색·고정 앱·최근 파일·전체 앱·전원 메뉴를 갖춘 One UI 시작 화면을 추가했습니다. 시작 화면과 독의 고정은 따로 저장하며, 시작 앱도 드래그 애니메이션과 함께 순서를 바꿀 수 있습니다.
- Windows 단독 키 입력을 처음부터 처리해 순정 시작 화면의 어두워졌다 밝아지는 현상을 막습니다. Windows 조합키와 순정 시작 메뉴 선택은 유지합니다.
- Now bar의 내용 창과 블러 창 모두 보이는 캡슐 안에서만 클릭을 받도록 수정했습니다. 접히거나 펼쳐져 있을 때 주변과 위쪽의 다른 창을 클릭할 수 있습니다.
- 포커스를 빼앗지 않는 One UI 알림 팝업을 추가했습니다. 실제 Windows 팝업과 대조해 기록만 남기는 알림, 방해 금지와 앱별 팝업 설정을 반영합니다.
- 알림을 누르면 원래 팝업·프로토콜·등록된 콜백 또는 일치하는 Windows 알림 기록을 통해 해당 동작을 실행합니다. 일치 여부가 불확실하면 Windows 알림 기록을 보여주며 발신 앱만 임의로 실행하지 않습니다.
- 입력 영역 계산을 캐시하고 백그라운드 작업과 복구 도우미는 이벤트 기반으로 유지했습니다. 배터리·미디어 세션 활성 상태의 최종 짧은 측정은 본체 CPU 평균 0.0517%, 도우미 0.0000%였습니다. 메모리 수치와 측정 한계는 검증 문서에 기록했습니다.

## 8.5.1

- 접힌 Now bar의 최대 너비를 오른쪽 상태 캡슐에 맞추고, 짧은 제목도 썸네일과 함께 왼쪽에 정렬했습니다.
- 접힌 캡슐의 재생 상태 아이콘을 없애고 썸네일과 제목만 표시합니다.
- 빠른 설정의 재생 중 미디어 플레이어 높이를 188에서 140 DIP로 줄였습니다. 빠른 설정과 펼친 Now bar 배경에 썸네일을 표시하고, 어두운 반투명 덮개로 글자 가독성을 유지합니다.
- 썸네일 배경은 최대 640픽셀로 제한해 한 번 생성한 뒤 공유합니다. 곡이 바뀌면 이전 배경은 수거할 수 있으며, 실시간 이미지 블러나 매 갱신마다 이미지 디코딩을 추가하지 않습니다.
- 제목이 같은 곡에서도 새 썸네일 이벤트를 반영하고, 곡 전환 직후에는 늦게 도착하는 이미지를 두 번만 재확인합니다. 같은 이미지 데이터는 다시 디코딩하지 않습니다.
- 빠른 설정의 밝기·음량·재생 위치 위에서 스크롤해 값을 바꾸는 기능은 기본으로 꺼집니다. 빠른 토글 또는 앱 설정의 ‘슬라이더 스크롤 조절’에서 켤 수 있습니다.
- 독의 검은 구분선 왼쪽은 고정 앱, 오른쪽은 실행 앱입니다. 선을 넘어 드래그하면 고정·해제가 저장됩니다. 잡은 아이콘이 커서를 따라가고 주변 아이콘은 자리를 비우며 움직입니다. 취소하면 원래 배치로 돌아옵니다.
- 평소 업데이트는 마지막 버전 숫자만 1씩 올립니다. 앞의 두 숫자는 소유자의 요청이 있을 때만 변경합니다.

## 8.5.0

- 복구 도우미가 패키지 환경에서 오래 실행된 뒤 코어 하나를 계속 점유하던 문제를 수정했습니다. 원본과 해시가 같은 복사본을 알림 연결용 패키지 밖에서 실행하고 준비 상태를 확인합니다. 20ms 반복 조회는 키 입력·프로세스 종료 이벤트 대기로 바꿨습니다.
- 배터리에서 패널이 닫혀 있으면 일반 갱신을 1Hz, 전체 화면에서는 0.5Hz로 낮춥니다. 화면이 꺼지면 반복 작업을 대부분 쉽니다. 음량·밝기·창 전환 이벤트와 패널을 여는 애니메이션은 별도로 처리합니다.
- 미디어·알림·음량 변경 이벤트를 활용하고, 기기·밝기·실행 앱·고정 앱의 보조 조회 횟수를 줄였습니다. 배터리의 긴 Now bar 제목은 한 번 흐른 뒤 쉬고 커서를 올리면 다시 움직입니다. 제목이 멈춘 동안에는 다시 그리지 않습니다.
- 0.5.5의 짧은 CPU 측정은 지연 발생한 도우미 문제를 놓쳤습니다. 이번 검사와 측정 범위는 [VALIDATION.md](VALIDATION.md)에 기록합니다. 완전 방전까지의 배터리 지속시간 비교는 아직 수행하지 않았습니다.

## 0.5.5

- 실행 중인 창의 실제 DWM 미리보기를 확대하고, 빠른 설정·Now bar의 미디어 플레이어를 통일했습니다. 출력 기기 이름과 아이콘형 전환 버튼을 함께 표시합니다.
- 재생 중인 미디어가 없으면 얇은 캡슐로 표시합니다. 알림 패널의 캘린더·빈 안내 카드는 제거하고 방해 금지 토글을 추가했습니다.
- Wi-Fi 신호별 곡선, 낮은 음량·밝기 모양, 팝업 블러·애니메이션, 바깥 클릭 닫기, Now bar 원래 자리 클릭, 항상 흰 배터리 숫자를 정리했습니다.
- 반복 조회를 줄이고 앱 아이콘은 화면에 보이는 것부터 읽습니다. 백그라운드 작업은 EcoQoS를 적용한 두 작업 스레드에서 처리하며 Windows가 E·LP-E 등 효율 코어를 선택하게 합니다. 특정 코어 번호나 CPU 종류에 고정하지 않습니다.
- 배터리 사용 중 일반 갱신 주기를 10Hz에서 5Hz로 낮춥니다. 애니메이션과 직접 키 입력 처리는 독립적으로 유지합니다. 배터리 지속시간 증가는 장시간 실측하지 않았습니다.
- 복구 도우미의 Windows 메시지 처리 누락으로 코어를 계속 점유하고 재시작 후 남던 문제를 수정했습니다. 메시지 루프와 파일 감시 대신 20ms의 네이티브 대기 사이에서 긴급 키만 확인합니다. 본체 종료 시 함께 끝나며 중복 실행을 거부합니다.
- 일반 EXE·바로가기 실행에서도 Windows 알림 연결 ID를 유지하며 설치·업데이트 경로 처리를 보완했습니다.

## 0.5.2 변경

- 썸네일 색을 반영하는 Now bar와 가변 길이·긴 제목 스크롤·미디어 제어를 추가했습니다.
- 펼침·접기는 고정된 창 안의 캡슐만 움직이게 바꿔, 복귀 중 반복되는 창 크기 변경과 블러 위치 갱신을 줄였습니다. 중간에 다시 눌러도 현재 위치에서 이어집니다. 투명 영역은 클릭을 통과시키며 Alt+Tab에 표시하지 않습니다.
- 앱·검색창을 줄이고 빠른 설정과 같은 회색 블러 및 연속적인 전환을 적용했습니다. 연결 세부 메뉴와 알림도 색을 맞췄습니다.
- 기능 영역을 실제 켜고 끌 수 있는 토글로 바꾸고, 전원 메뉴에 다시 시작을 추가했습니다. Windows 설정 아이콘은 다른 글자·아이콘과 같은 전경색을 따릅니다.

## 이전 변경

### 0.4.0

- 설정 → 시작과 검색 → 독의 시작 버튼에서 앱 목록과 Windows 시작 버튼을 별도로 선택합니다. 키보드 시작 키 설정과 독립적입니다.
- 연결된 무선 규격에 따라 상태 영역에 Wi-Fi 4·5·6·7을 표시합니다. 알 수 없는 규격이나 연결 해제 시 숫자를 숨깁니다.
- 활성 앱 아이콘을 다시 누르면 최소화합니다. 클릭 시 아이콘이 눌렸다가 튀어 오릅니다.
- 앱 목록·검색·빠른 설정·알림 패널을 밝은 반투명 유리 디자인으로 정리했습니다. Windows 설정은 검은색 단순 톱니 아이콘을 사용합니다.
- Windows 밝기 변경 이벤트를 즉시 반영하고 표시창을 갱신할 때 위치가 다시 이동하지 않도록 했습니다. 지원하는 Explorer 표시창을 식별한 경우 자체 표시창으로 대체합니다.

현재 확인 중인 항목: 이 PC에서는 독의 Windows 시작 메뉴 직접 호출 자동 검사가 검색창을 여는 현상이 남아 있습니다. 기본 앱 목록 모드는 유지되며, Windows 시작 메뉴 선택은 추가 확인이 필요합니다.

0.4.1: 빠른 설정 내부 카드·기능 버튼의 회색 반투명 농도를 높였습니다. 상단 전원 메뉴에서 전원 끄기·절전·잠금을 선택할 수 있습니다. 전원 끄기에 강제 종료 옵션을 사용하지 않습니다.

0.4.2: 독 알약과 아이콘은 앱 추가·종료 시 양방향으로 부드럽게 움직입니다. 최근 실행한 앱은 오른쪽 끝에 추가하고 포커스 변경으로 순서를 섞지 않습니다. 수동 드래그도 유지됩니다. 빠른 설정 표면은 더 투명한 회색 블러로 조정했습니다. Windows 밝기 표시창은 미리 투명하게 준비하며 정상 종료와 복구 도우미가 원래 상태로 되돌립니다.

0.4.3: 독에 이미 있는 앱은 실행·종료해도 위치가 유지되며, 독에 없던 앱만 맨 오른쪽에 추가합니다. 빠른 설정은 동적 블러 위의 검은 반투명 농도를 높이고, 활성 와이파이·블루투스·색 모드·음량 버튼과 슬라이더 채움 색을 같은 흰색으로 통일했습니다.
