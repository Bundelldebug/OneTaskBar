# One TaskBar

Windows 작업표시줄을 대체하는 독·런처·빠른 설정입니다. Windows 폰트와 설치된 앱의 원래 아이콘을 사용합니다. [English](README.md)

## 설치

[최신 릴리스](https://github.com/Bundelldebug/OneTaskBar/releases/latest)에서 **OneTaskBar-Setup.exe**를 받아 실행하고 설치를 누르세요. 자동 실행·바탕 화면 바로가기·설치 후 실행을 선택할 수 있습니다. 기본 설치와 사용에 관리자 권한이 필요하지 않으며 인증서 신뢰나 Windows 보안 정책을 바꾸지 않습니다.

- 실제 검증 환경: Windows 11 x64. Windows 10 2004 이상 x64와 .NET Framework 4.8도 호환 대상으로 삼지만 모든 Windows 빌드에서 셸 연동을 검증한 것은 아닙니다.
- 초기 배포 파일에는 코드 서명이 없습니다. Windows에서 알 수 없는 게시자 또는 SmartScreen 안내가 나올 수 있습니다. 릴리스의 SHA256SUMS로 파일을 확인할 수 있습니다.
- 프로그램: `%LOCALAPPDATA%\OneTaskBar\App`
- 설정: `%LOCALAPPDATA%\OneTaskBar\Data`
- 제거: Windows 설정 → 앱 → One TaskBar. 프로그램을 종료하면 Windows 작업표시줄이 복원되며, 제거해도 사용자 설정은 보관합니다.
- 기존 개인용 One UI 홈의 설정이 있으면 필요한 설정 파일만 한 번 가져옵니다. APK나 기존 로고는 가져오지 않습니다.

## 동작

설정에서 빠른 설정·알림센터·키보드 시작 키·검색을 각각 Windows 기본 화면 또는 One TaskBar 화면으로 고를 수 있습니다. 앱 화면에서 바로 입력하면 검색으로 넘어가며 한글 조합 중에는 기다립니다. 터치 스크롤과 트랙패드의 미세 스크롤을 지원합니다.

독의 시작 버튼은 검색·고정 앱·최근 파일·사용자 폴더·설정·전원 메뉴를 갖춘 One Taskbar 시작 화면을 엽니다. ‘모든 앱’을 누르면 기존 앱 화면으로 이동합니다. 시작 화면 고정과 독 고정은 별도로 저장되며, 앱 우클릭 메뉴에서 각각 고정·해제할 수 있습니다. 시작 앱은 드래그로 순서를 바꿀 수 있고, 주변 앱이 자리를 비켜 주는 애니메이션과 함께 독과 별도로 순서를 저장합니다. 시작 화면은 최대 940 × 620 DIP이며 빠른 설정과 같은 블러를 사용합니다. Windows 시작 키의 기존 선택은 유지합니다. One Taskbar 시작 키 모드에서는 단독 Windows 키를 누르는 순간부터 셸에 전달하지 않아 기본 메뉴의 어두워짐 효과를 막고, 조합 키는 정상 순서로 전달합니다.

빠른 설정에는 실제 음량·지원되는 화면의 밝기·Wi-Fi·블루투스·음악 재생·전원 모드 등이 연결됩니다. 지원하지 않는 장치나 설치되지 않은 삼성 앱 버튼은 자연스럽게 숨깁니다. 배터리가 없는 PC에서는 배터리 부분을 숨기거나 직접 입력한 1~9999 W를 표시할 수 있습니다. 이 숫자는 실시간 전력 측정값이 아닙니다.

빠른 설정의 기능 영역은 음소거·다크 모드·방해 금지·전력 절약·화면 유지·Wi-Fi·블루투스·독 애니메이션·자동 실행을 실제 상태와 연결합니다. 전력 절약은 Windows 성능 모드를 변경하며, 화면 유지는 앱 실행 중 자동 화면 꺼짐을 막습니다. 직접 절전을 선택하는 동작은 막지 않습니다. 빠른 설정·연결 세부 메뉴·알림·앱·검색은 같은 회색 동적 블러를 사용하며, 앱과 검색창 크기는 최대 720 × 680 DIP입니다.

왼쪽 아래 미디어 플레이어는 Windows의 재생 중이거나 일시 정지된 미디어를 표시합니다. 높이 44 DIP의 캡슐이 제목 길이에 맞춰 오른쪽 상태 캡슐의 너비(최대 282 DIP)까지 늘어나고, 썸네일과 제목은 짧은 제목에서도 왼쪽에 정렬됩니다. 긴 제목은 스크롤됩니다. 누르면 재생·이전·다음·재생 위치 컨트롤로 펼쳐집니다. 미디어 앱이 제공하는 기능만 활성화하며, 썸네일의 대표색을 배경에 반영하고 흰 글자의 가독성을 위해 밝기를 조정합니다. 공간이 부족하면 같은 줄에서 썸네일만 보이는 원형까지 줄고, 독 끝의 `…`에서 숨겨진 앱에 접근할 수 있습니다.

시작 화면과 앱 화면에서 앱을 겹치면 폴더를 만들고, 가장자리로 옮기면 순서를 바꿉니다. 폴더 이름과 내부 순서도 저장하며 시작·앱 화면·독 배치는 서로 독립적입니다.

설정 → 미디어 플레이어에서 큰 커버 펼침을 선택할 수 있습니다. 설정 → 충전 소리에서 파일을 선택하면 새 충전 연결 때 재생합니다. 시작 시 이미 연결되어 있으면 재생하지 않습니다.

검색 바로 오른쪽 버튼은 Windows 작업 보기를 열어 데스크톱을 전환합니다. 검색 결과는 방향키와 Enter로 조작할 수 있습니다. 앱 화면·검색·시작의 앱 우클릭 메뉴에는 데스크톱 실행 파일·바로가기의 ‘관리자 권한으로 실행’을 표시합니다. 독에는 표시하지 않으며 Windows 권한 확인을 거칩니다. 패키지 앱과 설정 URI는 이 방식의 관리자 실행을 지원하지 않습니다.

‘YouTube 고화질 커버’는 기본 꺼짐입니다. 켜면 삼성 브라우저의 현재 프로필에서 재생 제목과 정확히 일치하는 기록만 읽어 영상 ID를 확인하고 `i.ytimg.com`에서 공개 커버를 가져옵니다. 제목·쿠키·기록 행을 서버에 보내지 않으며 중복된 영상은 선택하지 않습니다. 조회 시간·다운로드 용량·시도 횟수를 제한하고 영상당 한 번 처리합니다. 현재 영상 한정 허용은 해당 영상에만 제한할 수 있습니다. 원본 커버는 최대 1280픽셀까지 보존하며 배경 이미지는 별도로 제한합니다. 원본이 작고 일치하는 고화질 커버를 구할 수 없으면 여전히 흐릿할 수 있습니다.

기본 설치는 **Windows 알림센터**를 사용합니다. 앱 설정 → Windows 알림 연결에서 자체 알림센터 연결을 진행할 수 있습니다. 선택적 로컬 패키지 등록 시 Windows가 관리자 승인을 한 번 요구할 수 있으며, 알림 접근 권한은 Windows 확인창에서 직접 허용해야 합니다. 연결 후 일반 실행·로그인에서도 등록된 ID를 다시 사용합니다. 이 연결용 패키지는 **미서명 로컬 테스트 ID**이며 배포용 코드 서명 패키지는 아닙니다. 설치기가 자동 등록하거나 보안 정책을 바꾸지는 않습니다. [알림 연결 안내와 제한](docs/NOTIFICATIONS.md)을 확인하세요.

알림 연결 후 ‘One Taskbar 알림 팝업’을 켜면 지원되는 Windows 배너를 둥근 블러 카드로 표시합니다. 실제 Windows 배너 내용과 새 알림을 대조해 기록 전용 알림이나 이전 알림을 다시 띄우지 않습니다. 최대 3개까지 표시하며 키보드 포커스를 빼앗지 않습니다. 팝업을 닫아도 알림 기록은 남고, 표시 중인 카드가 없으면 만료 타이머도 멈춥니다.

알림을 누르면 원래 Windows 알림 카드의 동작을 우선 사용합니다. 프로토콜·등록된 알림 콜백도 활용하며, 필요한 경우 Windows 알림 기록에서 앱·제목·본문이 일치하는 카드를 찾아 실행합니다. 대응하는 항목이 없거나 중복되어 구분할 수 없으면 앱만 임의로 여는 대신 Windows 알림센터에서 확인할 수 있도록 합니다.

## 단축키와 복구

| 단축키 | 기능 |
| --- | --- |
| Ctrl+Alt+H | One TaskBar 설정 |
| Ctrl+Alt+Q | 빠른 설정 |
| Ctrl+Shift+Tab+1 | **One TaskBar 자체를 강제 종료**하고 Windows 작업표시줄 복원 |

긴급 종료는 설정에서 끌 수 있습니다. 독립 복구 도우미가 감시하므로 UI가 응답하지 않아도 사용할 수 있습니다. 현재 사용 중인 다른 앱을 종료하는 기능은 아닙니다. Windows 보안 화면이나 도우미 자체까지 종료된 상황에서는 단축키를 처리할 수 없습니다.

## 빌드와 공개 자료

Windows PowerShell에서 `Build.ps1`, 이어서 `tools/BuildInstaller.ps1 -SkipBuild`를 실행하면 앱과 설치기를 만듭니다. NuGet이나 별도 SDK 다운로드가 필요하지 않습니다. 전체 빌드·검증 방법은 [README](README.md), 측정 결과는 [VALIDATION.md](VALIDATION.md)를 참고하세요.

원본 아이콘과 소스는 MIT 라이선스입니다. Samsung APK·추출 로고·배경화면·폰트·개인 스크린샷과 영상은 배포하지 않습니다. 설치된 다른 앱의 로고는 실행 중 해당 PC에서 읽으며 권리는 각 소유자에게 있습니다. Microsoft·Samsung과 무관한 독립 프로젝트이고, 제3자의 권리 주장 가능성이 전혀 없다고 보증하는 것은 아닙니다.

## Code signing policy

정식 서명은 아직 활성화되지 않았습니다. 무료 SignPath Foundation 서명을 신청하고 있으며 외부 심사 승인이 필요합니다. 승인 후 사용할 표기: “Free code signing provided by SignPath.io, certificate by SignPath Foundation”. [서명 정책 및 개인정보 처리 설명](docs/CODE_SIGNING.md)을 참고해 주세요. 개발용 미서명 파일은 정식 서명 배포본이 아닙니다.

## 9.0.0 베타 1 (개발 중 · 서명 승인 대기)

- 앱 설정 최상단의 **UI 버전 → 8.5 / 9.0 베타**에서 선택합니다. 기존 설치는 8.5를 유지하며, 9.0 배치는 `quick-layout-9.json`에 별도로 저장합니다. 전환하거나 9.0 배치를 초기화해도 8.5 순서와 크기는 유지합니다.
- 9.0 빠른 설정의 **배치 편집**에서 각 메뉴를 끌어 이동하고 오른쪽 아래 모서리를 끌어 크기를 조절합니다. 일반 메뉴는 가로 1~4칸 × 세로 1~5칸, 1×1은 완전한 원입니다. 겹치는 메뉴는 아래로 자리를 비키고 긴 배치는 스크롤합니다.
- 밝기·음량은 다크 모드·음소거 버튼과 독립되어 있으며 외곽 카드 테두리를 제거했습니다. 가로 1×1~4×1, 세로 1×1~1×5를 지원합니다. 버즈 출력 아이콘과 별도 음소거 버튼의 기존 동작은 유지합니다.
- 한 줄 높이는 중간 두께인 64 DIP입니다. 키보드 음량·밝기 조절바에도 같은 테두리 없는 캡슐 디자인을 사용합니다. 기능 토글은 기존처럼 패널 안에서 10개 아이콘과 이름으로 펼쳐지고, 접으면 원래 크기·위치로 복원합니다.
- 미디어 플레이어는 편집 시 최소 2×2입니다. 기본 4×2 크기일 때만 활성 미디어가 없으면 임시로 한 줄이 되고 아래 메뉴가 올라옵니다. 재생 세션이 다시 활성화되거나 편집을 시작하면 저장한 크기를 복원하며, 일시 정지된 세션과 다른 사용자 지정 크기는 유지합니다.
- One TaskBar 설정 진입 버튼은 집 모양으로 구분합니다. Windows 설정의 톱니바퀴와 설치된 삼성 설정 아이콘은 유지합니다.
- 편집 중 방향키로 이동·크기를 조절하고 Esc로 드래그를 취소할 수 있습니다. 빼기 버튼으로 숨긴 항목은 **항목 추가**에서 되돌립니다. 1×1 Wi-Fi·블루투스의 연결 관리는 오른쪽 클릭 또는 Shift+F10에서 엽니다.
- 이 소스의 베타 표기는 GitHub 배포 완료를 뜻하지 않습니다. 정식 서명 심사와 최종 배포 검증이 남아 있습니다.

## 8.5.7 (개발 중 · 정식 서명 승인 대기)

- 시작 화면의 최근 항목은 Windows가 관리하는 최근 문서 기록을 직접 읽어 원본 기록 시각순으로 표시합니다. Windows의 최근 기록 표시 설정과 정책을 따릅니다. 사용자 폴더·색인·앱 설치 날짜로 자체 목록을 만들던 조회는 제거했습니다. 순정 시작 메뉴의 전체 추천 순위, 최근 설치 앱, 클라우드 추천 목록을 그대로 내보낸 데이터는 아닙니다.
- 최근 항목의 ‘폴더 열기’를 ‘더 보기’로 바꿨습니다. 누르면 고정 앱 영역을 최근 항목 전용 화면으로 전환해 최대 24개를 표시하며 ‘뒤로’로 돌아갑니다. 검색·하단 메뉴·Windows와 연결 영역은 유지합니다.
- 잘린 알림은 오른쪽 펼치기 버튼으로 제목과 본문 전체를 읽고 다시 접을 수 있습니다. 앱별 알림 묶음을 펼치는 동작과 개별 내용 펼치기는 별개이며, 긴 내용은 알림센터 안에서 스크롤합니다. 원래 알림을 여는 동작도 유지합니다.
- 이미지가 있는 알림은 접힌 카드에서도 이미지를 표시합니다. 늦게 도착하는 원본 이미지 정보는 제한된 횟수만 다시 읽고, 알림센터를 열면 최신 정보를 갱신합니다. 이미지가 없으면 빈 그림이나 대체 이미지는 넣지 않습니다.
- Galaxy Buds 연결 정보를 오른쪽 아래 캡슐로 표시합니다. 등록 기기의 Windows 연결 상태 변경만 감지하며 주변 기기 검색이나 새 연결은 실행하지 않습니다. 시작할 때 이미 연결된 기기는 다시 알리지 않습니다. 삼성 설정의 버즈 연결 배너도 같은 캡슐로 모으고 앱 아이콘은 숨기되 제품 이미지는 유지합니다. 좌우·케이스 배터리 그림이 포함된 원본 알림은 작은 아이콘으로 축소하지 않고 본문 너비로 표시하며 알림센터에서도 유지합니다. 선택적 제품 이미지는 설치된 삼성 설정의 리소스를 읽고 배포 파일에는 넣지 않습니다.
- 버즈 배터리는 Windows가 제공하는 값만 사용하고, 좌우·케이스 정보는 삼성 원본 알림에 포함된 경우 표시합니다. 모르는 잔량을 만들지 않습니다. 방해 금지·전체 화면 상태를 따르며, 설정 → 패널 선택 → Galaxy Buds 연결 팝업에서 끌 수 있습니다. 전체 알림 팝업 설정이 꺼져 있으면 이 팝업도 표시하지 않습니다.
- Windows와 연결의 휴대폰 배터리에는 실제로 충전 중이라고 전달된 경우에만 번개를 표시합니다. 충전 여부가 제공되지 않으면 일반 배터리 아이콘으로 표시합니다.
- 원본 알림에 ‘연결’ 같은 동작 버튼이 있으면 해당 버튼과 고유 실행 인수를 유지합니다. 원본 배터리 그림이 표시된 뒤 일반 연결 이벤트가 도착해도 그림과 버튼을 덮어쓰지 않습니다.
- 블루투스에는 한 기기 연결 시 이름, 여러 기기 연결 시 실제 기기 수를 표시하며 일반·LE 중복 항목을 합칩니다. 설정에서 ‘주변 기기 연결 대신 Galaxy Buds 열기’를 켜면 버튼을 바꾸고 버즈 앱 창을 빠른 설정의 모서리 위치에 맞춥니다.
- Galaxy Buds 버튼은 설치된 버즈 앱의 배터리 원 안에 있는 이어버드 아이콘을 사용합니다. 버즈가 실제 소리 출력 장치일 때 음량바 안쪽, 빠른 설정·펼친 미디어 플레이어의 출력 표시, 키보드 음량 표시창도 같은 아이콘을 사용합니다. 별도 음소거 버튼은 기존 스피커 모양을 유지합니다. 아이콘은 96픽셀로 한 번 읽고 색상별 렌더링을 재사용합니다. 삼성 이미지는 배포 파일에 넣지 않으며 One TaskBar 자체 앱 아이콘도 바꾸지 않습니다.
- 빠른 설정·상세 화면의 버튼 호버 확대가 스크롤 영역이나 잘리는 카드 경계를 넘지 않도록 제한합니다. 클릭 피드백과 여유 공간에서의 호버 애니메이션은 유지합니다.
- 시작 메뉴 하단의 설정 버튼은 One TaskBar 설정을 엽니다. 고정된 Windows 설정 앱은 기존 동작을 유지합니다.
- 현재 개발용 본체·복구 프로그램은 이 PC에서 Smart App Control과 Defender가 켜진 상태로 실행·설치 검증을 통과했습니다. 여전히 미서명이며 다른 파일·빌드·PC의 허용을 보장하지 않습니다. 8.5.7 정식·베타 배포는 아직 공개하지 않았습니다. 정식 공개에는 승인된 발급자의 타임스탬프 서명과 보호 기능이 켜진 PC에서의 검증이 필요합니다. 이후의 최근 사용 앱 저장 보완 변경은 제외했고 보안 설정·예외·신뢰 인증서는 바꾸지 않았습니다.

## 8.5.6

- 독·시작·모든 앱·검색·숨겨진 앱의 아이콘을 Ctrl+Shift와 함께 클릭하면 지원되는 데스크톱 앱을 관리자 권한으로 실행합니다. Windows 권한 확인을 거치며 패키지 앱·설정 URI는 지원하지 않습니다.
- 독의 앱을 화면 왼쪽·오른쪽으로 끌면 분할, 가운데로 끌면 팝업 크기로 엽니다. 영역 미리 보기와 창 이동 애니메이션을 표시하고, Esc 또는 아래쪽 취소 영역으로 취소합니다. 설정 → 데스크톱의 ‘앱 드래그로 분할·팝업 열기’로 끌 수 있으며 독 안에서 순서를 바꾸는 기능은 유지됩니다. 현재 화면의 일반 창은 반대쪽에 함께 배치하며, 크기 변경이 제한된 창은 분할할 수 없습니다.
- 블루투스 목록에 기기 종류 아이콘·연결 상태와 ‘등록된 기기’/‘새 기기’를 표시합니다. 등록 기기를 누르면 관리 메뉴를 열며 연결 해제나 등록 삭제를 임의로 수행하지 않습니다.
- 검색 추천 앱은 최근 실행·활성화한 앱 순서입니다. 앱 ID와 시각만 최대 64개를 이 PC에 저장하고, 파일이나 창 제목은 저장하지 않습니다. 연속 사용 기록은 마지막 변경 후 한 번 저장합니다.
- 드래그 미리 보기와 안내창의 내용·블러를 함께 나타내고 숨깁니다. 미리 보기의 블러가 아래쪽 클릭을 가로막거나 따로 남는 문제와 드래그 취소 시 포커스 문제를 수정했습니다. 드래그 중 DPI 조회를 재사용하고 임시 타이머·입력 등록을 종료 시 해제합니다.

## 8.5.5

- 같은 앱의 알림을 최신 내용·시간·개수가 보이는 한 캡슐로 묶습니다. 펼치기·접기와 오른쪽 위 팝업에 애니메이션을 적용했습니다. 펼쳐 개별 알림을 열거나 지우고 앱별로 모두 지울 수 있으며 새 알림이 와도 펼친 상태와 기존 카드를 유지합니다.
- Wi-Fi·블루투스 세부 화면을 열 때마다 자동 재검색하고 오른쪽 새로고침 아이콘이 회전합니다. Wi-Fi 검색 완료 이벤트를 기다린 뒤 목록을 읽고 블루투스는 주변 기기 검색을 제한된 시간만 실행합니다. 화면을 닫으면 검색·로딩을 중단하며 이전 요청 결과는 무시합니다.
- 빠른 설정 → 배치 편집에서 기능 토글 묶음의 오른쪽 아래 곡선 손잡이를 끌어 크기를 조절합니다. 가로 1~4열과 세로 1~5행을 독립적으로 선택해 세로형·정사각형 등 모든 20가지 조합을 만들 수 있습니다. 가운데 ‘편집’을 누르면 전체 토글의 순서를 바꾸고, 완료하면 선택한 접힌 모양을 유지합니다. 손잡이에 포커스를 두고 방향키로도 조절할 수 있습니다.
- 좁은 화면에서도 미디어 플레이어를 독과 같은 줄에 배치합니다. 공간에 따라 제목을 줄이고 썸네일만 있는 44-DIP 원형까지 축소하며 미디어가 끝나면 공간을 돌려줍니다. 표시 중인 접기 애니메이션의 끝에서 창 좌표를 다시 바꾸지 않아 순간 깜빡임을 막고, 다음 표시 때는 작은 창으로 시작합니다.
- 앱이 많으면 고정 앱부터 유지하고 끝의 `…`에 커서를 올리거나 클릭해 나머지 앱을 엽니다. 숨겨진 앱은 위쪽 스크롤 팝업에서 실행·창 선택·우클릭 메뉴를 사용할 수 있습니다. 바깥 클릭으로 닫힙니다.
- 독 앱을 옮길 때 고정된 자리 기준으로 이동 대상을 판단하고 같은 최종 순서의 애니메이션을 반복 시작하지 않습니다. 빠르게 방향을 바꾸거나 고정 구역 경계를 넘을 때 이웃 아이콘이 흔들리는 현상을 줄였습니다.
- 실제 연결 경로가 유선랜이면 새 랜 포트 모양 아이콘으로 전환합니다. Wi-Fi 어댑터가 함께 있어도 활성 연결을 따르며 네트워크 변경 이벤트로 갱신합니다.
- GitHub #1의 자동 숨김 제보에 맞춰 Windows 설정 요청의 대상 창과 변경 확인을 수정했습니다. 독이 나타나고 숨을 때 캡슐·아이콘·블러·미디어를 함께 움직이며, 조작 유예 시간과 캡슐 사이의 여유 영역을 둡니다. 펼친 미디어는 자동 숨김을 잠시 멈추고 바깥 클릭으로 접히면서 함께 숨습니다. 일반 모드에서는 실제 작업 영역을 기준으로 독 위·아래 간격을 맞춥니다.
- 스토어 앱은 큰 타일 로고보다 작업표시줄용 배경 없는 아이콘을 먼저 읽습니다. 같은 패키지 앱의 아이콘 캐시를 공유해 중복 디코딩도 줄였습니다. 제보된 스토어판 Spotify는 이 PC에 없어 해당 버전의 직접 확인은 남아 있습니다.
- 삼성 성능 모드는 캡슐 안 원형 버튼을 조용함 → 저소음 → 최적화 → 고성능 순서로 배치하고 현재 모드를 밝게 표시합니다. 고성능에서는 OEM의 최대 팬 상태를 표시하며 상태를 읽을 수 없으면 이를 알립니다. 일시적인 읽기 실패에도 옵션은 유지합니다. **이 PC의 삼성 서비스는 외부 앱의 직접 변경을 거부해 자동 전환은 지원되지 않습니다.** 삼성 설정을 자동 실행하지 않고 사용자가 직접 누르는 열기 버튼을 제공합니다.
- 펼친 미디어 플레이어와 빠른 설정의 썸네일을 누르면 짧은 전환과 함께 현재 재생 세션의 앱을 엽니다.
- Wi-Fi 목록은 각 네트워크의 신호 세기·지원 Wi-Fi 세대·연결 및 보안 상태를 아이콘과 문구로 표시합니다. 휴대폰과 연결이 설치되어 있으면 맨 위에 Windows 인스턴트 핫스팟 연결 화면을 여는 항목을 제공합니다. **다른 앱이 등록한 핫스팟의 직접 목록 조회·연결은 공개 API로 지원되지 않아 Windows 화면에서 기기를 선택해야 합니다.**
- 시작·전체 앱·검색의 앱 우클릭 메뉴에 앱 제거 화면을 추가했습니다. 실행 경로가 없던 Win32 앱은 등록된 바로가기·실행 파일을 찾아 관리자 실행을 연결하고 인수를 유지합니다. 관리자 실행을 지원하지 않는 패키지 앱은 해당 항목을 비활성화합니다. 검색의 방향키 선택에서 기본 점선 테두리를 제거했습니다.
- 웹앱은 브라우저 실행 파일보다 정확한 앱 ID의 전용 바로가기·창 아이콘을 우선합니다. 설치된 PocketRisu 아이콘으로 확인했습니다.
- 바뀌지 않은 알림 스택·시계·로딩 그림을 재사용하고 미디어 전환의 중복 동기 다시 그리기를 줄였습니다. 최종 자원 측정과 실제 장치 확인 범위는 VALIDATION.md를 참고하세요.

## 8.5.4

- 다중 모니터에서 메뉴·시작 버튼이 다른 화면으로 이동할 수 있던 DPI 계산 순서를 수정했습니다. 창을 목적지 모니터에 배치한 뒤 배율을 읽으며 초기 독도 준비가 끝난 뒤 표시합니다.
- 캡처·전체 화면 전환 도중 빠르게 복귀했을 때 아이콘 투명도가 0으로 남던 문제를 수정했습니다. 숨긴 상태에서 앱 목록을 갱신해도 상태 캡슐이 다시 나타나지 않습니다.
- 시작할 때 Windows 자동 숨김을 강제로 켜지 않고 실제 Windows 선택을 따릅니다. One TaskBar 설정에도 같은 자동 숨김 스위치를 추가했습니다. 하단 2픽셀 감지 영역의 마우스 이벤트로 다시 표시하며 상시 고속 폴링은 추가하지 않았습니다. 메뉴·미리보기·미디어 조작 중에는 유지합니다.
- 자동 숨김 때 독의 작업 영역 예약을 반환해 최대화 창이 아래까지 채워지도록 했습니다. 표시 상태에서는 Windows 바의 기존 예약 공간을 중복해서 빼지 않습니다. 종료·충돌 복구도 사용자의 자동 숨김 변경을 보존합니다. 실제·합성 모니터 검증 범위는 VALIDATION.md를 확인하세요.

## 8.5.3

- 배포 전 `tools/Test-ReleaseDefender.ps1`로 본체·복구 도우미·설치·포터블 파일을 검사합니다. 보호 기능이 켜져 있고 파일 해시가 유지되며 새 탐지가 없어야 통과합니다. 보안 예외나 보호 설정을 변경하지 않습니다. 결과는 해당 파일과 검사 정의 버전에 한정되며, 정식 코드 서명은 별도 인증서가 필요합니다. Defender 탐지와 SmartScreen 평판은 별개입니다. [Microsoft 개발자 안내](https://learn.microsoft.com/en-us/defender-xdr/developer-faq), [오탐 파일 제출](https://www.microsoft.com/en-us/wdsi/filesubmission/).
- 독 검색 오른쪽 데스크톱 전환 버튼, 검색 방향키·Enter 조작, 앱 화면·검색·시작의 관리자 실행 메뉴를 추가했습니다. 한글 조합 중 실행을 막고 검색어의 일반 커서 조작을 유지합니다.
- 시작 화면과 앱 화면에서 드래그로 순서를 바꾸고, 앱을 겹쳐 폴더를 만들 수 있습니다. 폴더 이름·내부 순서·앱 꺼내기·폴더 풀기를 지원하며 시작·앱 화면·독의 배치는 따로 저장합니다.
- 시작 화면 오른쪽에 설치된 휴대폰과 연결의 기본 동반 카드 정보를 표시합니다. 연결·배터리 상태와 메시지·통화·사진·파일 보내기 바로가기를 제공하고, 화면이 좁으면 패널을 접습니다. 숨겨진 동안 계속 조회하지 않습니다.
- 삼성 설정이 설치된 지원 기기의 배터리 및 전원에 삼성 성능 모드를 표시합니다. 원본 삼성 설정을 통해 선택하며 자동 선택을 지원하지 않는 버전에서는 원래 성능 모드 화면을 엽니다. 펌웨어나 레지스트리의 성능 값을 직접 쓰지 않습니다.
- 알림의 실제 앱 아이콘과 원본 큰 이미지를 표시합니다. 그림이 없으면 대체 그림이나 빈 이미지 칸을 만들지 않으며, 네트워크로 새 이미지를 내려받지 않습니다.
- 충전 연결음에 직접 고른 소리 파일과 미리 듣기를 추가했습니다. 기본은 꺼짐이며 새 충전 연결 때만 재생합니다.
- 설정 → 미디어 플레이어에서 큰 커버 펼침을 선택할 수 있습니다. 이미지가 없으면 큰 커버 영역을 생략합니다. 실제 Windows 잠금 화면 교체는 지원하지 않습니다.
- 캡슐 기능의 표시 이름을 미디어 플레이어로 바꿨습니다. 원본 커버를 최대 1280픽셀까지 보존하고, 작은 원본을 보완하는 삼성 브라우저·YouTube 고화질 커버 옵션을 별도로 제공합니다.
- 사용자 지정 시작과 알림 팝업 이름을 One Taskbar로 정리했습니다. 숨긴 창은 20초 후 해제하고, 세부 화면의 숨은 타이머를 중지하며 아이콘 캐시를 48개·160픽셀로 제한했습니다. 최종 메모리·CPU와 측정 한계는 검증 문서를 확인하세요.

## 8.5.2

- 검색·고정 앱·최근 파일·전체 앱·전원 메뉴를 갖춘 One Taskbar 시작 화면을 추가했습니다. 시작 화면과 독의 고정은 따로 저장하며, 시작 앱도 드래그 애니메이션과 함께 순서를 바꿀 수 있습니다.
- Windows 단독 키 입력을 처음부터 처리해 순정 시작 화면의 어두워졌다 밝아지는 현상을 막습니다. Windows 조합키와 순정 시작 메뉴 선택은 유지합니다.
- 미디어 플레이어의 내용 창과 블러 창 모두 보이는 캡슐 안에서만 클릭을 받도록 수정했습니다. 접히거나 펼쳐져 있을 때 주변과 위쪽의 다른 창을 클릭할 수 있습니다.
- 포커스를 빼앗지 않는 One Taskbar 알림 팝업을 추가했습니다. 실제 Windows 팝업과 대조해 기록만 남기는 알림, 방해 금지와 앱별 팝업 설정을 반영합니다.
- 알림을 누르면 원래 팝업·프로토콜·등록된 콜백 또는 일치하는 Windows 알림 기록을 통해 해당 동작을 실행합니다. 일치 여부가 불확실하면 Windows 알림 기록을 보여주며 발신 앱만 임의로 실행하지 않습니다.
- 입력 영역 계산을 캐시하고 백그라운드 작업과 복구 도우미는 이벤트 기반으로 유지했습니다. 배터리·미디어 세션 활성 상태의 최종 짧은 측정은 본체 CPU 평균 0.0517%, 도우미 0.0000%였습니다. 메모리 수치와 측정 한계는 검증 문서에 기록했습니다.

## 8.5.1

- 접힌 미디어 플레이어의 최대 너비를 오른쪽 상태 캡슐에 맞추고, 짧은 제목도 썸네일과 함께 왼쪽에 정렬했습니다.
- 접힌 캡슐의 재생 상태 아이콘을 없애고 썸네일과 제목만 표시합니다.
- 빠른 설정의 재생 중 미디어 플레이어 높이를 188에서 140 DIP로 줄였습니다. 빠른 설정과 펼친 미디어 플레이어 배경에 썸네일을 표시하고, 어두운 반투명 덮개로 글자 가독성을 유지합니다.
- 썸네일 배경은 최대 640픽셀로 제한해 한 번 생성한 뒤 공유합니다. 곡이 바뀌면 이전 배경은 수거할 수 있으며, 실시간 이미지 블러나 매 갱신마다 이미지 디코딩을 추가하지 않습니다.
- 제목이 같은 곡에서도 새 썸네일 이벤트를 반영하고, 곡 전환 직후에는 늦게 도착하는 이미지를 두 번만 재확인합니다. 같은 이미지 데이터는 다시 디코딩하지 않습니다.
- 빠른 설정의 밝기·음량·재생 위치 위에서 스크롤해 값을 바꾸는 기능은 기본으로 꺼집니다. 빠른 토글 또는 앱 설정의 ‘슬라이더 스크롤 조절’에서 켤 수 있습니다.
- 독의 검은 구분선 왼쪽은 고정 앱, 오른쪽은 실행 앱입니다. 선을 넘어 드래그하면 고정·해제가 저장됩니다. 잡은 아이콘이 커서를 따라가고 주변 아이콘은 자리를 비우며 움직입니다. 취소하면 원래 배치로 돌아옵니다.
- 평소 업데이트는 마지막 버전 숫자만 1씩 올립니다. 앞의 두 숫자는 소유자의 요청이 있을 때만 변경합니다.

## 8.5.0

- 복구 도우미가 패키지 환경에서 오래 실행된 뒤 코어 하나를 계속 점유하던 문제를 수정했습니다. 원본과 해시가 같은 복사본을 알림 연결용 패키지 밖에서 실행하고 준비 상태를 확인합니다. 20ms 반복 조회는 키 입력·프로세스 종료 이벤트 대기로 바꿨습니다.
- 배터리에서 패널이 닫혀 있으면 일반 갱신을 1Hz, 전체 화면에서는 0.5Hz로 낮춥니다. 화면이 꺼지면 반복 작업을 대부분 쉽니다. 음량·밝기·창 전환 이벤트와 패널을 여는 애니메이션은 별도로 처리합니다.
- 미디어·알림·음량 변경 이벤트를 활용하고, 기기·밝기·실행 앱·고정 앱의 보조 조회 횟수를 줄였습니다. 배터리의 긴 미디어 플레이어 제목은 한 번 흐른 뒤 쉬고 커서를 올리면 다시 움직입니다. 제목이 멈춘 동안에는 다시 그리지 않습니다.
- 0.5.5의 짧은 CPU 측정은 지연 발생한 도우미 문제를 놓쳤습니다. 이번 검사와 측정 범위는 [VALIDATION.md](VALIDATION.md)에 기록합니다. 완전 방전까지의 배터리 지속시간 비교는 아직 수행하지 않았습니다.

## 0.5.5

- 실행 중인 창의 실제 DWM 미리보기를 확대하고, 빠른 설정·미디어 플레이어의 미디어 플레이어를 통일했습니다. 출력 기기 이름과 아이콘형 전환 버튼을 함께 표시합니다.
- 재생 중인 미디어가 없으면 얇은 캡슐로 표시합니다. 알림 패널의 캘린더·빈 안내 카드는 제거하고 방해 금지 토글을 추가했습니다.
- Wi-Fi 신호별 곡선, 낮은 음량·밝기 모양, 팝업 블러·애니메이션, 바깥 클릭 닫기, 미디어 플레이어 원래 자리 클릭, 항상 흰 배터리 숫자를 정리했습니다.
- 반복 조회를 줄이고 앱 아이콘은 화면에 보이는 것부터 읽습니다. 백그라운드 작업은 EcoQoS를 적용한 두 작업 스레드에서 처리하며 Windows가 E·LP-E 등 효율 코어를 선택하게 합니다. 특정 코어 번호나 CPU 종류에 고정하지 않습니다.
- 배터리 사용 중 일반 갱신 주기를 10Hz에서 5Hz로 낮춥니다. 애니메이션과 직접 키 입력 처리는 독립적으로 유지합니다. 배터리 지속시간 증가는 장시간 실측하지 않았습니다.
- 복구 도우미의 Windows 메시지 처리 누락으로 코어를 계속 점유하고 재시작 후 남던 문제를 수정했습니다. 메시지 루프와 파일 감시 대신 20ms의 네이티브 대기 사이에서 긴급 키만 확인합니다. 본체 종료 시 함께 끝나며 중복 실행을 거부합니다.
- 일반 EXE·바로가기 실행에서도 Windows 알림 연결 ID를 유지하며 설치·업데이트 경로 처리를 보완했습니다.

## 0.5.2 변경

- 썸네일 색을 반영하는 미디어 플레이어와 가변 길이·긴 제목 스크롤·미디어 제어를 추가했습니다.
- 펼침·접기는 고정된 창 안의 캡슐만 움직이게 바꿔, 복귀 중 반복되는 창 크기 변경과 블러 위치 갱신을 줄였습니다. 중간에 다시 눌러도 현재 위치에서 이어집니다. 투명 영역은 클릭을 통과시키며 Alt+Tab에 표시하지 않습니다.
- 앱·검색창을 줄이고 빠른 설정과 같은 회색 블러 및 연속적인 전환을 적용했습니다. 연결 세부 메뉴와 알림도 색을 맞췄습니다.
- 기능 영역을 실제 켜고 끌 수 있는 토글로 바꾸고, 전원 메뉴에 다시 시작을 추가했습니다. Windows 설정 아이콘은 다른 글자·아이콘과 같은 전경색을 따릅니다.

## 이전 변경

### 0.4.0

- 설정 → 시작과 검색 → 독의 시작 버튼에서 앱 목록과 Windows 시작 버튼을 별도로 선택합니다. 키보드 시작 키 설정과 독립적입니다.
- 연결된 무선 규격에 따라 상태 영역에 Wi-Fi 4·5·6·7을 표시합니다. 알 수 없는 규격이나 연결 해제 시 숫자를 숨깁니다.
- 활성 앱 아이콘을 다시 누르면 최소화합니다. 클릭 시 아이콘이 눌렸다가 튀어 오릅니다.
- 앱 목록·검색·빠른 설정·알림 패널을 밝은 반투명 유리 디자인으로 정리했습니다. Windows 설정은 검은색 단순 톱니 아이콘을 사용합니다.
- Windows 밝기 변경 이벤트를 즉시 반영하고 표시창을 갱신할 때 위치가 다시 이동하지 않도록 했습니다. 지원하는 Explorer 표시창을 식별한 경우 자체 표시창으로 대체합니다.

현재 확인 중인 항목: 이 PC에서는 독의 Windows 시작 메뉴 직접 호출 자동 검사가 검색창을 여는 현상이 남아 있습니다. 기본 앱 목록 모드는 유지되며, Windows 시작 메뉴 선택은 추가 확인이 필요합니다.

0.4.1: 빠른 설정 내부 카드·기능 버튼의 회색 반투명 농도를 높였습니다. 상단 전원 메뉴에서 전원 끄기·절전·잠금을 선택할 수 있습니다. 전원 끄기에 강제 종료 옵션을 사용하지 않습니다.

0.4.2: 독 알약과 아이콘은 앱 추가·종료 시 양방향으로 부드럽게 움직입니다. 최근 실행한 앱은 오른쪽 끝에 추가하고 포커스 변경으로 순서를 섞지 않습니다. 수동 드래그도 유지됩니다. 빠른 설정 표면은 더 투명한 회색 블러로 조정했습니다. Windows 밝기 표시창은 미리 투명하게 준비하며 정상 종료와 복구 도우미가 원래 상태로 되돌립니다.

0.4.3: 독에 이미 있는 앱은 실행·종료해도 위치가 유지되며, 독에 없던 앱만 맨 오른쪽에 추가합니다. 빠른 설정은 동적 블러 위의 검은 반투명 농도를 높이고, 활성 와이파이·블루투스·색 모드·음량 버튼과 슬라이더 채움 색을 같은 흰색으로 통일했습니다.
