# One TaskBar 9.5.8 베타 1

9.0.11의 모니터 선택, 터치 키보드·캐스트 바로가기와 음소거·데스크톱 전환 수정을 포함합니다.

- 설정 → 미디어 플레이어에 Dynamic Island를 추가했습니다. 기본은 꺼짐입니다. 미디어와 충전·음량·밝기 상태를 표시하며, 전체화면에서는 숨깁니다.
- 상단 안전 영역을 48에서 32로 줄였습니다. 닫힌 미디어 캡슐에는 제목 없이 썸네일과 재생 상태를 표시합니다. 클릭하면 제목과 재생 조작부가 펼쳐집니다.

UI 8.5·9.0·9.5를 선택할 수 있습니다. 설치는 `OneTaskBar-Setup.exe`, 무설치는 포터블 ZIP을 사용하세요.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
