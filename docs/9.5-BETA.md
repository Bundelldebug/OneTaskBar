# One TaskBar 9.5.6 베타 1

[9.0.9 정식의 공통 변경](RELEASE_NOTES_9.0.9.md)에 UI 9.5 유리 재질을 포함합니다. UI 8.5·9.0도 선택할 수 있습니다. 알림 밀기 삭제·커스텀 알림음·추천 앱 12개·삼성 노트 Alt+Tab 수정·데스크톱 전환 최적화가 포함되며, 부드러운 재생 웨이브와 일시정지 전환은 UI 9.0·9.5에 적용됩니다.

기존 설정과 고정 앱·배치를 유지합니다. 이 버전은 **미서명 베타**이며, Windows 실행 차단 가능성과 전체 RAM 150MB 미만 목표 미달 상태는 남아 있습니다.

## 이전 9.5.2 베타 1

[9.0.5 정식의 공통 변경](RELEASE_NOTES_9.0.5.md)에 UI 9.5 유리 재질을 포함합니다. UI 8.5·9.0도 선택할 수 있습니다.

- 키보드 음량·밝기 조절바는 짙은 반투명 바탕과 흰 채움을 사용해 밝은 창 위에서도 구분되도록 했습니다. 빠른 설정의 기존 조절바 형태는 유지합니다.
- 알림 팝업·Alt+Tab·창 미리보기의 블러와 바탕 색상을 빠른 설정과 동일하게 맞췄습니다. 창 미리보기의 실시간 Windows 썸네일은 유지됩니다.
- 아이콘 방식 항목 추가·첫 빈칸 배치·기능 토글 확장·출력 기기 애니메이션·정식의 최적화가 모두 포함됩니다.
- 23개 로컬 회귀 검사, 설치 파일 검증 및 Defender 검사를 통과한 변경입니다. 모든 장치·앱·다중 모니터 조합을 검증했다는 의미는 아닙니다.

이 버전은 **미서명 베타**입니다. Windows 실행 차단 가능성은 남아 있으며 합산 RAM 150MiB 미만 목표도 아직 달성하지 못했습니다.

## 이전 9.5.1 베타 1 변경
9.0.4 정식의 공통 수정에 UI 9.5 유리 재질을 포함한 공개 베타입니다. UI 8.5·9.0도 계속 선택할 수 있습니다. 이전 베타 9 이후 로컬 적용본에서 검증한 변경을 포함합니다.

## 이번 버전 변경

- 선택된 삼성 성능 모드 아이콘과 버즈 연결 버튼의 색상을 수정했습니다. 알림 팝업에는 밝은 화면 위에서도 읽을 수 있는 짙은 바탕을 적용했습니다.
- 유리효과의 붓·펜·그림자 자원을 재사용해 반복 그리기 할당과 비용을 줄였습니다. 알림 이미지·연결 버튼과 기존 애니메이션은 유지합니다.
- 빠른 설정·알림·시작·앱·검색의 **라이트 모드에 기존 다크 모드의 회색 유리 배경과 흰 글자 디자인을 그대로 옮겼습니다.** 새 다크 모드는 검정에 가까운 배경을 사용합니다. UI 8.5·9.0·9.5에 공통으로 적용됩니다.
- 앱 화면의 검색칸도 시작·검색 화면과 같은 크기와 입력 스타일을 사용합니다. 테마를 바꿀 때 검색어·열린 폴더·최근 항목의 더 보기 상태를 유지합니다.
- 기존 라이트 재질은 70% 투명도를 유지합니다. 새 다크 모드는 가독성을 위해 더 짙은 바탕을 사용하며, 독의 기본 투명도와 별도 색 모드 선택은 유지합니다. 설정창 자체의 라이트·다크 색상은 기존대로입니다.
- 좌우 작업표시줄에서 미디어 플레이어를 모니터 맨 위에 배치합니다.
- 측면 상태바를 앱 독과 같은 너비로 줄이고 일반 배터리 바도 얇게 표시합니다.
- **설정 → 화면 → 듀오 스타일 상태 아이콘**에서 배터리 원 게이지, 가운데 네트워크 아이콘, 아래 음량 네 점을 한 아이콘으로 표시할 수 있습니다. 기본은 켜짐입니다. 점은 원의 곡률을 따르고, 듀오 모드에서는 별도 배터리 바를 표시하지 않습니다.
- 듀오 원 게이지 위쪽 가운데에 배터리 잔량 숫자를 표시합니다. 충전기를 연결하면 번개와 원 게이지 충전 애니메이션이 나타나고, 끝나면 잔량 숫자로 돌아옵니다. 기존 애니메이션 및 충전 효과 설정을 따릅니다.
- **설정 → 화면 → 밝기·음량 수치 표시**를 켜면 빠른 설정과 키보드 조절바 끝에 현재 값을 표시합니다. 기본은 꺼짐입니다.
- 같은 영상의 재생목록 주소가 여러 개 쌓였을 때 고화질 커버 조회가 실패하던 문제를 수정했습니다.
- 듀오 배터리 게이지는 충전 연결 중 초록색을 유지하며, 위·아래 작업표시줄에서 아이콘 사이의 여백을 줄였습니다. 일반 가로 배터리는 기존 두께와 충전 애니메이션을 사용하고, 좌우에서만 얇은 배터리를 사용합니다.
- 새 이슈 #3의 시작 메뉴 배경과 듀얼 모니터 전체화면 문제를 수정했습니다. 블러를 사용할 수 없는 환경에서는 테마에 맞는 배경을 표시하고, 전체화면 여부는 모니터마다 판정합니다.

## 설정 위치

- 투명도 조절 항목은 없습니다. 독과 기존 재질의 기본 투명도는 **70%**이며, 이번에 추가한 짙은 다크 패널에는 별도의 어두운 바탕을 적용합니다. 이전에 저장된 투명도 값은 적용하지 않으며 다른 설정은 유지합니다.
- **설정 → 화면 → One TaskBar 색 모드**: Windows 따르기, 라이트, 다크를 선택합니다. Windows 자체 색 모드는 변경하지 않습니다.
- **설정 → 데스크톱 → 작업표시줄 위치**: 아래쪽, 위쪽, 왼쪽, 오른쪽을 선택합니다.
- **설정 → 데스크톱 → 작업표시줄 배경**: 기본 재질, 단색, 로컬 이미지를 선택합니다.
- UI 8.5 / 9.0 / 9.5 베타 선택과 기존 배치는 유지됩니다.

## 이번 수정

- 70% 투명도 위에 독·시작 메뉴 전체를 덮던 진한 가독성 보정 바탕을 제거했습니다. 실제 창에 적용되는 기본 배경이 30% 불투명도를 사용하며 카드의 유리 음영도 옅게 조정했습니다. 글자와 아이콘의 불투명도는 유지합니다.
- UI 버전 선택에 내부 클래스 이름이 보이던 문제를 수정했습니다. 스크롤 내용을 중복해서 그리던 효과를 제거해 그리기 비용과 메모리를 줄였습니다.
- 좌우 독에서는 미디어 플레이어가 같은 가장자리의 원형 커버로 표시되고 화면 안쪽으로 펼쳐집니다. 상단 배치도 실제 팝업 영역에 맞게 보정했습니다.

- 연결된 Wi-Fi·Bluetooth의 흰 원 안에 짙은 아이콘을 표시하고, 8.5·9.0의 음소거·버즈 아이콘 색과 개별 동작 버튼의 원형 배경을 통일했습니다.
- 투명도 조절 기능은 없으며 기본 배경 투명도는 70%입니다. 화면 픽셀을 읽거나 글자·아이콘을 번지게 하는 효과는 사용하지 않습니다.
- **설정 → 화면 → 작업표시줄 색 모드 분리**에서 독과 나머지 패널에 서로 다른 라이트·다크 모드를 적용할 수 있습니다.
- UI 버전 선택을 키보드로도 조작할 수 있는 펼침 목록으로 바꿨습니다. 9.5 키보드 음량·밝기 조절바에도 유리 재질을 적용하고, 켜진 패널 토글은 흰색으로 표시합니다.
- 고화질 커버 설정이 켜져 있으면 일반 미디어 카드에도 현재 영상의 커버를 가져옵니다. 늦게 기록되는 영상은 제한된 간격으로 재시도합니다. 현재 제목에 정확히 일치하는 로컬 기록만 조회하며 제목은 외부로 보내지 않습니다.
- Win 키로 연 시작 메뉴도 다른 곳을 클릭하면 닫힙니다. 창 활성화에 실패한 경우에도 동작하며 메뉴 안의 클릭과 앱 끌기는 유지합니다.

- 실시간 Windows Composition 블러 위에 타일별 윗면 반사선, 둥근 안쪽 광택과 아랫면 그림자를 추가했습니다. 1×1 원형과 기존 알약 조절바 모양은 유지합니다. Apple Liquid Glass와 제공된 사진을 참고한 Windows용 재질이며, Apple의 렌더링 엔진을 사용하는 것은 아닙니다.
- 시작 최근 항목에 로컬 사진 미리보기와 Windows의 캐시된 문서·영상 썸네일을 표시합니다. 128픽셀 비트맵을 제한된 캐시에 보관하고 화면을 닫으면 대기 요청을 취소합니다.
- 기본 작업표시줄을 가릴 때 남던 작업 영역을 반환합니다. 논리적 자동 숨김 선택은 유지하고 종료 시 복원합니다.
- 삼성 브라우저의 동영상 전체화면 프레임 보정은 캡션 없는 전체화면에만 적용하며 일반 최대화 창은 제외합니다.

- 설정 검색에서 일치하지 않는 카드와 구분선을 함께 제거하고 검색 결과 없음, 검색어 지우기를 추가했습니다. 카테고리 아이콘의 의미와 세로 정렬도 수정했습니다.
- 밝은 화면 뒤에서도 읽을 수 있도록 텍스트 대비와 카드 경계를 조정했습니다. 8.5·9.0의 빠른 설정·알림에도 라이트 모드 블러와 읽기 쉬운 전경색을 적용했습니다.
- 테마 전환 때 열려 있는 설정 페이지와 검색어를 보존하면서 설정·런처·패널의 색을 함께 갱신합니다.
- Wi-Fi 상세의 뒤로 가기·새로 고침은 정사각형 영역을 사용합니다. 편집·완료·알림 같은 텍스트 버튼은 실제 높이에 맞는 알약 곡률을 사용합니다.
- 과한 글래스 명암과 이중 원형 테두리를 줄이고, 미디어 플레이어의 바깥 테두리를 제거했습니다. 기존 음량·밝기 캡슐 형태는 유지합니다.
- 작업표시줄 시간·날짜에 추가되었던 알약 테두리를 제거했습니다.
- Alt+Tab과 미리보기 클릭에서 실제 전면 창을 확인하고, 겹친 창의 명시적인 소유 관계와 모달 창을 처리합니다. 최대화 상태를 보존하고 입력 큐는 항상 분리합니다. 새 사용자 입력 뒤에는 지연 재시도로 포커스를 빼앗지 않습니다.
- 최근 앱 기록의 원자적 파일 교체에 백업을 사용하고, 일시적인 저장 실패에는 제한된 재시도를 적용했습니다.

## 검증 범위

자체 검사와 격리 GUI 검사로 설정 검색·테마·사진 미리보기·재질·기존 빠른 설정·활성 창 전환을 확인합니다. 네 방향 독은 실제 작업 영역과 복원을 검사하고, 다중 DPI 및 음수 모니터 좌표는 160개 조합으로 계산을 검사합니다. 삼성 브라우저 보정은 자사 테스트 창의 프레임 제거·복원과 일반 창 제외를 확인하며, 모든 브라우저·외부 창 꾸미기 조합에서의 확인을 뜻하지 않습니다. 정확한 검증 내역은 VALIDATION.md에 기록합니다.

메모리 해제 검사는 전체 RAM 150 MiB 미만 목표 달성을 뜻하지 않습니다. 베타도 미서명 상태이므로 Windows가 실행을 차단할 수 있습니다. 보안 정책이나 백신 예외는 변경하지 않습니다.
