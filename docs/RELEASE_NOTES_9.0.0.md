# One TaskBar 9.0.0

- 빠른 설정의 항목을 개별적으로 이동하고 크기를 조절할 수 있습니다.
- 일반 항목은 1×1–4×5, 미디어는 2×2–4×5를 지원합니다. 밝기·음량 바는 가로 4×1 또는 세로 1×5까지 늘릴 수 있습니다.
- 기능 토글을 그룹 밖으로 꺼내거나 다시 넣을 수 있습니다.
- 미디어 카드 크기에 따라 커버와 재생 버튼 배치가 바뀝니다.
- 키보드 조절바의 숨김·재호출, 앱 아이콘 갱신과 설정 화면을 수정했습니다.
- 블러 없는 단색 독 옵션을 추가했습니다.

설정에서 UI 8.5와 9.0을 선택할 수 있으며 두 배치는 따로 저장됩니다.

[Windows CI](https://github.com/Bundelldebug/OneTaskBar/actions/runs/40080799572)

설치: `OneTaskBar-Setup.exe` · 포터블: `OneTaskBar-Portable-x64.zip`

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
