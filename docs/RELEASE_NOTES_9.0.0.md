# One TaskBar 9.0.0

9.0.0 정식 릴리스입니다. **설치 파일과 실행 파일은 코드 서명되지 않았으며, Windows에서 실행을 차단하거나 알 수 없는 게시자 경고가 표시될 수 있습니다.** 유지관리자가 이 내용을 알리는 조건으로 미서명 공개를 승인했습니다. 보호 기능을 끄거나 예외를 추가하지 마세요.

## 주요 변경

- 빠른 설정을 개별 이동·크기 조절 가능한 4열 그리드로 바꿨습니다. 일반 항목은 1×1~4×5, 미디어는 2×2~4×5를 지원합니다. 밝기·음량은 가로 4×1 또는 세로 1×5까지 조절합니다.
- 앱 설정 맨 위에서 8.5와 9.0 UI를 선택합니다. 두 배치는 별도로 저장하며 기존 고정 앱과 8.5 설정을 보존합니다.
- 기능 토글 내부 편집을 복구하고 첫 줄 표시·대칭·아이콘 크기를 수정했습니다. 그룹에서 독립 토글로 빼거나 다시 넣을 수 있으며, 주변 기기 연결과 Galaxy Buds를 함께 배치할 수 있습니다.
- 미디어 카드의 큰 썸네일 블러를 복구하고 크기에 맞춰 커버·정보·재생 버튼 배치를 바꿨습니다. 기본 4×2만 미디어 미재생 시 한 줄로 줄어듭니다.
- 음량 아이콘에서 소리 및 출력을 엽니다. 밝기·음량 바는 60 DIP로 조정하고 키보드 조절바가 통째로 사라지도록 수정했습니다. 투명도 증가는 키보드 조절바에만 적용하며, 조절바가 다시 나타나지 않던 문제도 수정했습니다.
- 미디어 플레이어 펼침·접힘을 렌더링 주기에 맞추고 불필요한 재그리기를 줄였습니다. 숨겨진 조절바와 미사용 커버 이미지 자원도 정리합니다.
- 블러 없는 회색 단색 독 옵션과 읽기 쉬운 앱 설정 화면을 추가했습니다. One TaskBar 설정 아이콘은 집 모양입니다.
- 오래된 앱 이름·기본 아이콘과 독에서 새 아이콘이 갱신되지 않던 문제를 수정했습니다. Windows 바로가기의 실제 아이콘을 사용하며 고정 위치와 실행 중 창을 유지합니다.

## 검증과 제한

- 54개 자체 검사, 9.0 UI·8.5 크기·8.5.7 기능 회귀 검사와 실제 설치 앱의 이름·아이콘 비교를 통과했습니다. 조절바 숨김·재호출, 토글 분리·재결합, 독 버튼의 아이콘 갱신도 검사합니다.
- 설치 파일의 정상 실행·추출 검증을 통과했고 설치 파일·포터블의 19개 구성 파일이 검증한 빌드와 일치합니다. 본체·복구 프로그램·설치 파일·포터블은 Defender 검사에서 새 관련 탐지 없이 통과했습니다. 배포 파일은 첨부한 `SHA256SUMS.txt`와 비교할 수 있습니다.
- SignPath 신청이 거절되어 코드 서명이 없습니다. Defender 검사 통과와 실행 성공은 코드 서명이나 모든 PC에서의 실행 허용을 뜻하지 않습니다. Windows 보호 기능을 끄거나 예외를 추가하지 않습니다.
- 전체 메모리 150 MiB 미만 목표는 아직 달성하지 못했습니다. 실제 측정 조건과 수치는 `VALIDATION.md`에 기록합니다.
