# One TaskBar 9.0.1

**이 버전의 설치 파일과 실행 파일은 미서명입니다. Windows에서 실행을 차단하거나 알 수 없는 게시자 경고를 표시할 수 있습니다.** 코드 서명 인증서는 발급되지 않았으며, 바이러스 검사 통과가 게시자 인증을 대신하지 않습니다.

## 수정 및 개선

- 창이 하나만 열려 있어도 One TaskBar Alt+Tab 화면을 표시합니다. 같은 창을 반복 선택할 때 미리보기와 배치를 다시 계산하지 않으며, 마지막 창이 닫히면 전환 화면과 관련 자원을 정리합니다.
- Alt+Tab에 실시간 창 미리보기, 앱 아이콘, 키보드·클릭·휠 선택과 페이지 이동을 추가했습니다. 이미 열린 창과 최대화된 창이 실제로 맨 앞으로 오도록 수정했습니다. Windows 기본 Alt+Tab을 사용하는 옵션도 제공합니다.
- 로그인 시작을 현재 사용자 권한의 지연 없는 로그인 작업으로 옮겼습니다. 저장된 앱·고정 정보를 먼저 표시하고 전체 앱 검색과 장치 초기화는 첫 화면 이후에 진행합니다. 기존 자동 실행 선택을 유지합니다.
- 9.0 미디어 플레이어에 중앙 정렬된 `제목 · 아티스트`, 긴 제목 자동 스크롤과 재생 중 웨이브를 적용했습니다. 작은 독 플레이어는 빠른 설정의 기본 미디어 카드와 같은 높이로 줄였습니다. 일시 정지·숨김·애니메이션 감소 설정에서는 웨이브가 멈춥니다. 8.5 디자인은 유지합니다.
- 시작 화면은 최근 항목 네 줄이 보이도록 높이를 늘리고 선택한 디스플레이의 작업 영역과 배율에 맞춥니다. 작은 화면에서는 스크롤할 수 있습니다.
- 검색·시작·앱 화면 애니메이션의 중단·재호출을 부드럽게 처리하고, 애니메이션 후 아이콘이 기본 아이콘으로 남는 문제를 수정했습니다. 검색 결과 갱신을 묶고 임시 그리기 캐시를 해제합니다.
- 펼친 기능 토글의 행·이름 간격을 늘렸습니다. 부가 정보가 없는 독립 토글 이름은 아이콘과 중앙 정렬하며, Buds 등 추가 정보는 유지합니다.
- 배터리 20% **이하**에서 충전 중이 아닐 때 기존의 검은 충전량 부분만 빨간색으로 표시합니다. 충전 중 표시와 나머지 회색 영역은 유지합니다.
- Windows 작업표시줄 대체 모드를 켤 때 설정 창이 빈 화면으로 남는 문제를 수정했습니다.

## 검증 및 제한

- 58개 자체 검사와 단일 창 Alt+Tab, 다른 프로세스의 창 활성화, 로그인 등록, 8.5·9.0 빠른 설정, 미디어 20개 크기, 시작 크기, 지연 아이콘, 애니메이션 및 자원 정리 검사를 통과했습니다.
- 설치 파일의 정상 추출과 포터블의 19개 구성 파일을 검증한 빌드와 비교합니다. 배포 파일의 SHA-256은 함께 제공하는 `SHA256SUMS.txt`에 기록합니다.
- 메모리 150 MiB 미만 목표는 아직 달성하지 못했습니다. 측정 조건과 알려진 제한은 `VALIDATION.md`를 참고하세요. 강제 GC나 작업 집합 줄이기로 수치를 낮추지 않습니다.
- 부팅 후 실제 로그인 완료까지의 시간은 재부팅 환경에서 측정하지 않았습니다. 로그인 작업의 설정 지연 제거와 앱 내부 첫 화면 경로를 검증했습니다.
- Windows 보호 기능, 인증서 신뢰 또는 예외 설정을 변경하지 않습니다.
