# One TaskBar 9.0.1

- 창이 하나뿐이어도 자체 Alt+Tab 화면이 열리도록 수정했습니다.
- 선택한 창이 맨 앞으로 오지 않던 문제를 수정했습니다.
- 로그인 자동 실행의 지연을 없애고 앱·장치 검색을 첫 화면 표시 뒤로 옮겼습니다.
- 미디어 제목을 중앙에 정렬하고 긴 제목 자동 스크롤과 재생바 웨이브를 추가했습니다.
- 시작 메뉴에 최근 항목 네 줄이 보이도록 높이를 조절했습니다.
- 기능 토글 간격, 낮은 배터리 표시와 빈 설정창 문제를 수정했습니다.
