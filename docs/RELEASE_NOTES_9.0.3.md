# One TaskBar 9.0.3

투명도를 70%로 설정했는데도 독과 시작 메뉴가 거의 불투명하게 보이던 문제를 수정했습니다. 기본 배경 위에 덮이던 진한 가독성 보정 바탕을 제거해 실제 창 배경에 70% 투명도·30% 불투명도를 적용합니다. 투명도 조절 항목은 추가하지 않습니다.

- 빠른 설정·알림·상세 메뉴·시작 화면에도 같은 기본 재질을 적용하고 카드 음영을 옅게 조정했습니다.
- 글자·아이콘의 불투명도, 선택된 토글의 대비와 기존 원형·알약 모양은 유지합니다. 별도로 선택한 독의 단색·이미지 배경과 블러 끄기 옵션도 유지합니다.
- 실제 표시되는 창의 바탕을 검사하도록 회귀 검사를 보강했습니다. 기존 설정·고정 앱·레이아웃을 보존합니다.

정식은 UI 8.5와 9.0을 제공합니다. UI 9.5는 별도의 9.5.0 베타 9에서 선택할 수 있습니다.

**미서명 배포:** Windows가 실행을 차단할 수 있습니다. 보안 정책이나 백신 예외는 변경하지 않으며 정상 실행·설치 및 Defender 검사 후 공개합니다. 전체 RAM 150 MiB 미만 목표는 아직 달성하지 못했습니다.
