# One TaskBar 9.5.13

- 시작 메뉴, 검색, 앱 서랍을 미리 준비해 두어 첫 클릭부터 바로 열립니다.
- 세로 작업표시줄에서 시계가 잘리던 문제를 고쳤습니다.
- GoogleBook 스타일에서 전체화면일 때 상단이 검은 띠가 되고, 시계와 배터리가 계속 보입니다. 설정의 '전체화면 검은 띠'가 켜져 있을 때 적용됩니다.
- 터치로 고정 앱이나 목록 항목을 잠깐 누르고 있으면 끌어서 순서를 바꿀 수 있습니다. 바로 쓸어 넘기면 이전처럼 스크롤됩니다.
- 알림 배너와 팝업 애니메이션이 화면 주사율에 맞춰 더 부드럽게 움직입니다. 120Hz 화면에서는 재생바 물결도 120Hz로 움직이고, 배터리를 쓸 때는 60Hz로 줄여 전력을 아낍니다.
- 전체화면 미디어의 재생바 끝이 잘려 보이던 문제를 고쳤습니다.
- 바탕화면 위젯을 시작할 때 한 번만 만들어, 앱 시작 직후의 멈칫거림을 줄였습니다.
- 설정의 'Dynamic Island'를 '다이나믹 아일랜드'로 표기합니다.
- 소프트웨어 정보에 상세 버전(9.5.13 A1A1)이 표시되고, 앱 안 업데이트가 이런 빌드 코드를 인식합니다.

플루이드 UI는 별도의 10.0.0 베타에서 제공합니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
