# One TaskBar 10.0.0 A1A2 Beta

플루이드 UI 베타의 두 번째 빌드입니다. 설정 맨 위의 'UI 버전'에서 '플루이드 베타'를 고르면 켜집니다.

- 시작 메뉴가 플루이드 애니메이션 없이 그냥 나타나던 문제와, 첫 클릭 때 1초쯤 늦게 열리던 문제를 고쳤습니다.
- 패널이 열리는 도중에 다시 누르거나 Esc를 누르면 패널이 한순간 다 열린 모습으로 튀었다가 닫히던 문제를 고쳤습니다. 이제 그 자리에서 바로 되돌아갑니다.
- 다이나믹 아일랜드는 접혀 있을 때 검은색으로 펀치홀을 가리고, 펼쳐질 때만 플루이드 유리와 빛이 나타납니다.
- GoogleBook 스타일에서 단축키로 연 빠른 설정과 알림이 상단바에서 내려옵니다.
- 위젯을 시작할 때 한 번만 만들어 앱 시작 직후의 멈칫거림을 줄였고, 배터리를 쓸 때는 재생바 물결을 60Hz로 줄여 전력을 아낍니다.

앱 안 업데이트는 일반 버전만 확인하므로, 베타는 이 페이지에서 직접 받아야 합니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
