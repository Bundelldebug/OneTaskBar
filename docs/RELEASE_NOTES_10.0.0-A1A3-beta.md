# One TaskBar 10.0.0 A1A3 Beta

플루이드 UI 베타의 세 번째 빌드입니다. 설정 맨 위의 'UI 버전'에서 '플루이드 베타'를 고르면 켜집니다.

- 관리자 권한으로 실행한 게임에서도 Alt+Tab 창 전환과 Win 키가 동작하고, 최소화된 관리자 권한 창을 독에서 눌러 다시 켤 수 있습니다. 설정의 '관리자 권한 창 지원'을 켜면 Windows 확인이 한 번 나옵니다. 앱 본체는 일반 권한이라 알림 연결도 그대로 쓸 수 있습니다.
- 버즈를 연결할 때 음량바가 연결 알림을 가리던 문제를 고쳤습니다. 케이스 배터리가 함께 뜨는 삼성 알림이 더 먼저 보입니다.
- AI 셀렉트 같은 캡처 화면 위로 독이 올라오던 문제를 고쳤습니다.
- 다이나믹 아일랜드 검색에서 파일도 찾고, 방향키와 Enter로 고를 수 있습니다.
- 데스크톱 스타일이 프리셋입니다(커스텀 데스크톱, Windows, Mac, GoogleBook). 옵션을 따로 바꾸면 '커스텀 데스크톱'이 선택됩니다.
- 빠른 설정의 소리 및 출력에서 '앱별 음량' 화면으로 들어가 앱마다 음량을 조절하고, 앱 아이콘을 눌러 그 앱만 음소거할 수 있습니다.
- 앱 화면의 '앱 자동 폴더 정리'(기본 꺼짐): 비슷한 앱을 큰 폴더로 묶어 앱 9개를 한눈에 보여 줍니다.
- 설정 맨 위에 UI 버전이 있습니다. 설정에서 '베타 버전 받기'를 켜면 업데이트 확인이 베타도 찾고, '피드백 보내기'로 GitHub 이슈를 바로 쓸 수 있습니다.
- 이슈 18(독 미리보기 페이지 이동 시 닫힘), 버즈 연결 알림의 위치(하단 중앙), 저장공간·카메라 공유 알림을 고쳤습니다.- 플루이드: 데스크톱 전환 창이 스프링으로 열리고 닫힙니다. 독에서 앱을 켜고 최소화할 때와 나우바가 오가는 움직임을 더 눈에 띄고 빠르게 다듬었습니다.
- 플루이드: '배경에 맞춤'이 슬라이드쇼·Spotlight·배경화면 엔진 등 다른 PC의 바탕화면에서도 동작하고, 새로 설치하면 플루이드로 시작합니다.
- 리퀴드 글래스 카드 질감을 다시 만들었습니다.

설정의 '베타 버전 받기'를 켜면 앱 안에서 베타도 업데이트할 수 있습니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
