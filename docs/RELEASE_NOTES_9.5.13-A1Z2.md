# One TaskBar 9.5.13 A1Z2

- 설정에서 '관리자 권한 창 지원'을 켜고 끌 때 앱이 멈추거나 다시 시작되던 문제를 고쳤습니다. Windows 확인창은 앱과 따로 처리되어 오래 열어 두어도 앱이 멈추지 않고, 켜도 앱이 다시 시작되지 않습니다. 관리자 도우미가 앱과 함께 종료되고 사라지면 자동으로 다시 시작됩니다.
- 설정의 데스크톱 스타일 미리보기가 4칸일 때 잘려 보이던 것을 고쳤습니다.
- 배경화면 읽기를 보강했습니다(슬라이드쇼·단색·읽기 실패 대비). 배경화면을 바꾸면 곧바로 반영됩니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
