# One TaskBar 9.0.5

- 창이 없는 바탕 화면에서 독이 사라지던 문제를 수정했습니다.
- 시계 옆에 바로가기를 최대 4개까지 배치할 수 있습니다.
- 빠른 설정 항목을 검색해 추가하고 기능 토글 그룹에 넣거나 뺄 수 있습니다.
- 출력 기기 메뉴에 미디어 정보, 커버 배경과 전환 애니메이션을 적용했습니다.
- 알림 아이콘 해상도와 최근 검색의 모양·배치를 수정했습니다.

설치: `OneTaskBar-Setup.exe` · 포터블: `OneTaskBar-Portable-x64.zip`

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
