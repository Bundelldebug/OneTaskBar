# One TaskBar 9.0.5

UI 8.5·9.0을 제공하는 정식 업데이트입니다. UI 9.5 유리 재질은 9.5.2 베타에서 제공합니다.

- 활성 앱이 없는 바탕 화면에서 독의 실제 창이 숨겨진 채 복구되지 않는 문제를 수정했습니다. 전체화면이나 자동 숨김으로 의도적으로 숨긴 상태는 유지합니다.
- 창 미리보기·Alt+Tab·알림 팝업의 바탕을 빠른 설정과 같은 블러와 색상으로 맞췄습니다.
- 시계 옆 상태 영역에 블루투스·Galaxy Buds·달력·화면 캡처·작업 관리자·One TaskBar 설정 중 최대 4개를 배치할 수 있습니다.
- 연결된 Galaxy Buds 버튼은 선택된 상태로 표시됩니다. 주변 기기 연결·Windows 설정·화면 캡처·작업 관리자도 기능 토글 그룹에 넣거나 밖으로 뺄 수 있습니다.
- 기능 토글에 앱 설정 22개를 개별 아이콘으로 추가했습니다. 항목 추가는 검색 가능한 아이콘 목록으로 열리고, 새 항목은 기존 배치를 옮기지 않고 위에서부터 첫 빈 공간에 들어갑니다. 많은 토글은 그룹 안에서 스크롤됩니다.
- 소리 및 출력 메뉴에 현재 곡·썸네일·재생 버튼, 선택 출력의 음량바, 기기별 아이콘을 적용했습니다. 어두운 내부 색상, 커버 배경 블러와 전환 애니메이션을 추가하고 모서리 밖으로 그림이 새는 현상을 수정했습니다.
- 배치 크기 조절 시 내용과 편집 테두리가 함께 움직입니다. 초기화 버튼의 버전 숫자를 제거했습니다.
- 알림 앱 아이콘은 원본 해상도를 최대 256픽셀까지 보존하며, 더 선명한 설치 앱 리소스가 있으면 사용합니다.
- 독의 검색·데스크톱 보기 아이콘과 호버 효과를 다듬었습니다. 검색창은 최근 검색이 주제별 설정보다 먼저 나오며 검색어 칩은 알약 모양으로 표시됩니다.
- 변하지 않은 토글·이름·접근성 정보의 반복 갱신을 줄이고, 사라진 알림 앱의 이미지 캐시를 해제합니다. 연결 감시가 중단되면 남아 있던 버즈 연결 상태도 정리합니다.

개발자를 위해 빠른 설정을 구성·편집·상태 갱신 파일로 분리하고, [디버깅 안내](DEBUGGING.md)와 기능별 검사·자원 측정 도구를 추가했습니다. 로컬과 CI는 같은 검사 진입점을 사용합니다.

기존 설정·고정 앱·배치를 유지합니다. 설치 파일과 포터블은 **미서명**이며 Windows가 실행을 차단할 가능성은 남아 있습니다. 코드 서명·보안 정책·백신 제외 설정은 변경하지 않습니다. 합산 RAM 150MiB 미만 목표는 아직 달성하지 못했습니다.
