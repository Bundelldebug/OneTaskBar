# One TaskBar 9.5.13 A1Z3

- '관리자 권한 창 지원'을 켜거나 끌 때 관리자 권한 등록 프로세스가 강제 종료되던 문제를 고쳤습니다. 일부 PC에서 이 프로세스가 CPU를 계속 쓰고 작업표시줄이 멈추거나, 실제로는 켜졌는데 "저장하지 못했습니다"가 뜨고 앱을 다시 시작해야 동작하던 현상이 이 문제였습니다. 이제 허용하면 바로 적용됩니다.
- 앞에 떠 있는 관리자 권한 창의 독 아이콘을 누르면 최소화됩니다.
- 관리자 도우미가 CPU를 비정상적으로 쓰면 스스로 멈추고, 다시 시작하는 간격을 늘립니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
