# One TaskBar 9.5.6

- 설정 > 외관에 **리퀴드 글래스**(기본 꺼짐)를 추가했습니다. 실시간 블러에 채도를 더하고 틴트를 얇게 해 뒤의 창과 색이 더 투명하게 비칩니다. UI 9.5와 동적 블러가 켜져 있어야 합니다.
- 시간으로 움직이던 애니메이션(페이드, 호버, 패널·알림 열고 닫기, 토글, 독 아이콘)을 감쇠 스프링 곡선 하나로 통일해 시작은 빠르고 도착은 부드럽게 했습니다.
- 숨겨진 아이콘 트레이의 아이콘 가장자리가 계단처럼 보이던 문제를 고쳤습니다.
- 다른 앱 창이 알약으로 들어가거나 나올 때 창 자리에 윤곽선이 보일 수 있던 문제를 줄이고, 들어갈 때의 기울기를 약하게 했습니다.
- 큰 글래스 타일에 위쪽 반사광을 더했습니다.
- 설정의 블러·크기 막대를 음량·밝기 막대 모양으로 바꾸고, 글자 크기와 대비를 키우고, 항목을 소제목으로 묶었습니다.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
