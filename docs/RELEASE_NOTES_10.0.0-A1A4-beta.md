# One TaskBar 10.0.0 A1A4 Beta

- 플루이드 UI의 '배경에 맞춤' 빛 색을 다시 만들었습니다. 배경화면에서 가장 눈에 띄는 색을 골라 쓰고, 무채색 배경은 은은한 은색으로 처리하며, 배경화면을 바꾸면 바로 따라갑니다. 슬라이드쇼, Windows 추천(Spotlight), 모니터별 배경, 단색 배경도 읽습니다.
- 설정에서 '관리자 권한 창 지원'을 켜고 끌 때 앱이 멈추거나 다시 시작되던 문제를 고쳤습니다. Windows 확인창을 오래 열어 두어도 앱이 멈추지 않습니다.
- 설정의 데스크톱 스타일 미리보기가 잘려 보이던 것을 고쳤습니다.
- 9.5.13 A1Z2의 수정 사항을 포함합니다.

베타 버전입니다. 서명되지 않은 빌드이며 Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
