# One TaskBar 10.0.1 A1A1 Beta

- Dex 모드에서 시작 버튼을 다시 누르면 시작 메뉴가 닫힙니다. (#30)
- Dex 모드에서 시작·앱 목록이 열릴 때 이전 화면이 잠깐 비치거나 끊기던 문제를 고쳤습니다. 이제 버튼에서 부드럽게 커져 나옵니다. (#30)
- 다이나믹 아일랜드에 '스퀘어클 아일랜드' 옵션이 생겼습니다. 아일랜드를 스퀘어클 모양으로 바꾸고, 앨범·상태 아이콘과 제목을 함께 보여 줍니다. 음악을 듣는 중에 충전하면 음악이 왼쪽의 작은 아일랜드로 나뉩니다. 기본값은 꺼짐입니다.
- 다이나믹 아일랜드가 닫힐 때 네모난 검은 상자가 비치던 문제와, 펼칠 때 한 번에 튀어 커지던 문제를 고쳤습니다.
베타 버전입니다. 서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
