# One TaskBar 9.5.0

9.5 베타에서 추가한 기능과 수정 사항을 모두 정식에 포함했습니다. UI 8.5·9.0도 계속 선택할 수 있습니다.

- UI 9.5의 실시간 유리 효과와 Dynamic Island를 제공합니다. 아일랜드에는 미디어·새 알림과 충전·음량·밝기 상태가 표시됩니다. 펼친 미디어는 검정 상단과 커버 대표색의 블러 배경으로 나뉘며, 음량·밝기는 기존 캡슐형 바를 사용합니다.
- 전체화면 미디어 화면, 측면 독용 세로 미디어 캡슐과 앱 최소화·복원 전환 효과를 추가했습니다. 커버 크기 전환은 전체화면 미디어 화면에서 지원합니다.
- 트레이 아이콘의 현재 상태와 고해상도 원본을 반영하고, 어두운 아이콘의 가독성을 개선했습니다. Windows 기본 트레이도 선택할 수 있습니다.
- 포터블 폴더 이동 후 자동 시작 등록 오류와 설치 위치 변경 후 알림 연결 오류를 수정했습니다. Windows 10 구형 트레이의 호환 처리를 추가했습니다. (#11, #12)
- 미디어 앱 전환, 캡슐 잘림·깜빡임, 설정에서 뒤로 갈 때 화면이 겹치는 문제를 수정했습니다.
- 상태 영역 바로가기에 ‘바탕화면 보기’를 추가했습니다.
- 듀오 상태 아이콘은 기본 꺼짐입니다. 기존 설정과 고정 앱·배치는 유지합니다.

전체화면 미디어 화면은 별도 PC 잠금 버튼을 제공합니다. Windows 보안 잠금화면을 대체하지 않습니다.

Windows 10 트레이는 구형 도구 모음으로 재현해 검사했으며, 실제 Windows 10 PC에서의 확인은 남아 있습니다.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
