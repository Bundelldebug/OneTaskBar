# One TaskBar 10.0.0 A1B1 Beta

- 플루이드 UI: 시작·검색·빠른 설정·알림창이 열릴 때 누른 독 조각이 그대로 펼쳐져 창이 됩니다. 검색은 검색 아이콘, 알림은 시계, 빠른 설정은 Wi-Fi·스피커 아이콘이 창이 되고, 상태 영역은 그만큼 줄어든 채 창이 닫힐 때 돌아옵니다.
- 플루이드 UI의 알림 팝업이 하단바에서 빛나며 튀어나옵니다.
- 리퀴드 글래스를 Prism 재질로 다시 만들었고, 설정의 '리퀴드 글래스 굴절'(기본 꺼짐)을 켜면 패널·독·알림 팝업의 가장자리에서 뒤 화면이 휘어 보입니다.
베타 버전입니다. 서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
