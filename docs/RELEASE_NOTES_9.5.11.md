# One TaskBar 9.5.11

- 하단바 글자색이 뒤 배경에 맞게 바뀝니다. 시작·중앙·오른쪽 바가 각각 한 덩어리로 흰색 또는 검정을 고르므로, 검은 배경에서도 읽을 수 있습니다.
- 데스크톱 스타일이 프리셋으로 동작합니다. Mac에서 다른 스타일로 바꾸면 리퀴드 글래스·블러·하단 나우바가 바꾸기 전 상태로 돌아옵니다.
- 배경 프리셋 카드에 바탕화면·잠금화면 미리보기를 넣었습니다. 배경을 바꾼 뒤에도 위젯 블러가 이전 배경으로 남던 문제를 고쳤습니다.
- 자동 밝기 때문에 밝기 표시가 계속 뜨던 문제를 고쳤습니다. 밝기 키를 누를 때만 표시됩니다.
- GoogleBook 스타일에서 상단바가 검은 줄 뒤에 숨던 문제를 고쳤습니다.
- Win+Shift+S와 PrintScreen 캡처가 검색 단축키에 막히던 문제를 고쳤습니다.
- 120Hz 화면에서 애니메이션이 120프레임으로 동작합니다. 발열이 걱정되면 설정의 **60Hz 모드**를 켜세요(앱을 다시 시작하면 적용). 끝없이 반복되는 Island 막대 애니메이션은 30프레임으로 줄였습니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
