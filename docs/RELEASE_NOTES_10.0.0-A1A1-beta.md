# One TaskBar 10.0.0 A1A1 Beta

9.5 다음 인터페이스인 **플루이드 UI**의 베타입니다. 설정 맨 위의 'UI 버전'에서 '플루이드 베타'를 고르면 켜집니다. 9.5.13의 변경 사항도 모두 들어 있습니다.

- 패널이 하단바에서 물방울처럼 떨어져 나와 유리 알약으로 퍼지고, 바 쪽에서 빛이 지나가며 내용이 나타납니다. 닫을 때는 같은 과정이 거꾸로 일어납니다.
- 유리를 얇게 하고, 유리 뒤에서 번지는 글로우를 중심으로 바꿨습니다. 글로우 색은 설정의 '플루이드 UI'에서 고르거나 끌 수 있고, '배경에 맞춤'은 바탕화면의 주요 색을 따릅니다.
- 알림은 앱 아이콘의 주요 색으로 빛납니다(설정에서 끌 수 있음).
- 다이나믹 아일랜드는 접혀 있을 때 검은색으로 펀치홀을 가리고, 펼쳐질 때만 플루이드 유리와 빛이 나타납니다.
- 미디어 창이 캡슐로 들어가고 나올 때, 전체화면 미디어의 플레이어와 위젯, 바탕화면 위젯에도 플루이드 스타일이 적용됩니다.

베타라서 애니메이션과 색이 바뀔 수 있습니다. 문제가 있으면 UI 버전을 9.5로 되돌리면 이전 모습으로 돌아갑니다. 앱 안 업데이트는 일반 버전만 확인하므로, 다음 베타는 직접 받아야 합니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
