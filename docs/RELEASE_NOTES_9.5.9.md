# One TaskBar 9.5.9

- Dynamic Island가 미디어 재생 중에도 아래로 커지지 않고 가로로만 넓어집니다. 길이는 줄이고 두께는 조금 키웠으며(대기 44×22, 미디어 88×22), 위쪽 안전 영역도 이에 맞춰 얇아졌습니다. 펼친 아일랜드와 작은 커버의 이미지가 더 선명합니다.
- 설정 > 미디어 플레이어에 **상단 상태 표시줄**을 추가했습니다. 안드로이드처럼 왼쪽에 시계·날짜(알림센터), 재생 중인 미디어, 알림이 온 앱 아이콘을, 오른쪽에 네트워크·소리·배터리(빠른 설정)를 두며, 글자색은 뒤 화면 밝기를 따라 바뀝니다. 켜면 아래쪽 나우바와 상태 영역은 숨겨지고, 알림센터는 왼쪽 시계 아래에서, 빠른 설정은 오른쪽 상태 아이콘 아래에서 내려옵니다. 배터리는 아래쪽 독과 같은 알약이며 충전 애니메이션도 이 자리에서 나옵니다. 미디어 알약은 나우바처럼 나타나고, 누르면 알약이 상단바 바로 아래 카드로 커지며(큰 커버 설정 반영) 알림 아이콘이 날짜 쪽으로 옮겨 갔다가, 접거나 다른 곳을 누르면 알약으로 돌아옵니다. 시계·아이콘 사이 빈틈도 눌리며, Wi-Fi·소리 아이콘은 아래쪽 독과 같은 것을 씁니다.
- 미디어 앱 창이 들어가고 나오는 애니메이션의 목적지를 나우바와 Dynamic Island 중에서 고를 수 있습니다. Dynamic Island가 켜져 있으면 기본으로 아일랜드로 들어갑니다.
- 설정에 **가벼운 효과**를 추가했습니다. 포인터를 따라 움직이는 유리 빛, 리퀴드 글래스, 미디어 전환의 배경 흐림을 끄고 파형·제목 갱신을 줄입니다. 그래픽 등급이 낮거나 논리 프로세서 4개 이하, 메모리 6GB 이하인 PC는 자동으로 켜집니다.
- "작업표시줄까지 최대화" 옵션을 켠 상태에서 Excel처럼 제목 표시줄을 직접 그리는 Office 창이 전체화면 앱으로 잘못 인식돼 작업표시줄이 숨겨지고 자동 숨기기도 두 번째부터 올라오지 않던 문제를 고쳤습니다.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
