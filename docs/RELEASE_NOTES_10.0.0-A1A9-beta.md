# One TaskBar 10.0.0 A1A9 Beta

- 이슈 28: 탐색기·설정 같은 기본 창에서 GoogleBook 상단바 색이 채워지지 않던 문제를 고쳤습니다.
- 독의 검색 버튼과 다중 데스크톱 버튼을 설정에서 끌 수 있습니다.
- 트레이에서 카카오톡을 눌러도 창이 안 열리면 다시 실행해 창을 띄웁니다.
- 달력 위젯에 4x4 크기와 월 넘기기 버튼(‹ ›)이 생겼습니다. 월 제목을 누르면 이번 달로 돌아옵니다.
- 알림 팝업이 오른쪽 위 대신 오른쪽 아래 상태 표시 옆에 뜨고, 어두운 바탕에 밝은 글씨로 읽기 쉽게 바꿨습니다.
- 나우바 창 이동 애니메이션이 화면 주사율(최대 240Hz)에 맞춰 더 부드럽게 움직입니다.
베타 버전입니다. 서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
