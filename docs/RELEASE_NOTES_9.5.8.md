# One TaskBar 9.5.8

- 설정 > 개인 설정에 **숨겨진 아이콘 패널 크기**(50~130%)를 추가했습니다. 패널의 칸과 아이콘이 함께 커지거나 작아집니다. (#13)
- 세로 작업표시줄의 상태 영역에서 숨겨진 아이콘 단추, 빠른 설정 아이콘, 배터리, 시계가 같은 간격으로 놓이고 영역을 채웁니다. (#13)
- 작업표시줄 자동 숨기기를 켠 상태에서 Windows 키를 누르거나 검색 창을 열면 작업표시줄 전체가 함께 나타납니다. 패널을 닫으면 다시 숨겨집니다.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
