# One TaskBar 9.5.13 A1Z5

- 영어, 일본어, 중국어를 지원합니다. 기본값은 Windows 표시 언어를 따르고, '소프트웨어 정보'에서 바꿀 수 있습니다. 번역은 아직 다듬는 중이라 일부 문구는 한국어로 남을 수 있습니다.
- 검색에서 영어 자판으로 친 한글(qmfkdnwj → 브라우저)과 영어 앱 이름의 한글 이름(chatgpt 등)도 찾습니다.
- 알림 권한을 허용해도 알림이 뜨지 않고 "패키지를 열 수 없습니다 0x80070003"이 나오던 문제를 줄였습니다.
- 따로 실행한 앱(Steam, Chrome 등)을 독에 고정한 뒤 열면 문서 폴더가 열리던 문제를 고쳤습니다.
- 빠른 설정이나 알림을 열 때 CPU 사용이 오르던 현상을 줄였습니다.
- 접힌 Now Bar의 썸네일을 누르면 미디어 앱을 열지 않고 Now Bar만 펼칩니다.
- 알림 창의 미디어 플레이어 버튼이 잘리던 문제를 고치고 빠른 설정 4x2 플레이어와 같은 크기로 맞췄습니다.
- 둥근 사각형(스쿼클) 아이콘에도 입체 테두리를 넣었습니다.
- 설정의 버튼이 Glass 계열 UI에서 어색하게 보이던 모양과 글씨를 정리했습니다.
서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
