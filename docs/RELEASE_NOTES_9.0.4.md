# One TaskBar 9.0.4

UI 8.5·9.0을 제공하는 정식 업데이트입니다. UI 9.5 유리 디자인은 별도의 9.5.1 베타에서 제공합니다.

- 빠른 설정·알림·시작·앱·검색의 라이트 모드에 기존 다크 디자인을 옮기고, 검정에 가까운 새 다크 모드를 추가했습니다.
- 삼성 성능 모드에서 선택된 아이콘이 흰 원 안에서 사라지던 문제와 버즈 연결 버튼의 대비를 수정했습니다. 밝은 웹페이지 위에서도 알림 팝업을 읽을 수 있도록 바탕과 글자색을 맞췄습니다.
- 듀오 스타일 상태 아이콘에 배터리 잔량, 충전 애니메이션, 연결 중 초록색 게이지와 곡선 형태의 음량 점을 표시합니다. 시스템 글꼴이 달라도 잔량 숫자가 잘리지 않도록 보정합니다. 별도 배터리 바는 숨기며, 듀오 스타일은 설정에서 끌 수 있습니다.
- 좌우 작업표시줄에서는 미디어 플레이어를 맨 위에 두고 상태바와 배터리 바를 얇게 표시합니다. 위·아래 배치의 일반 배터리는 기존 두께와 충전 애니메이션을 사용합니다.
- 밝기·음량 조절바 끝의 숫자 표시 옵션을 추가했습니다. 기본은 꺼짐입니다.
- 같은 YouTube 영상의 재생목록 주소가 여러 개 쌓였을 때 고화질 썸네일 조회가 실패하던 문제를 수정했습니다. 기존 조회 동의와 현재 제목의 정확한 일치 조건을 유지합니다.
- 모니터마다 전체화면 창을 판정해 다른 화면이 활성화되어 있어도 해당 작업표시줄을 숨깁니다. 실시간 블러를 사용할 수 없을 때에는 읽을 수 있는 대체 배경을 사용합니다.
- 검색 입력 스타일을 통일하고, 테마 전환 시 검색어·열린 폴더·최근 항목 더 보기 상태를 보존합니다.

자체 검사, Windows GUI·수명주기 검사, 설치 파일 대조와 Defender 검사를 거쳐 배포합니다. 전체 RAM 150 MiB 미만 목표는 아직 달성하지 못했습니다. 다중 모니터 판정은 합성 좌표와 앱 소유 창으로 검증했으며 모든 실제 모니터 조합에서 확인한 것은 아닙니다.

미서명 배포입니다. Windows SmartScreen·조직 보안 정책에 따라 실행이 차단될 수 있습니다. 백신 예외나 보안 정책 변경은 하지 않습니다. 기존 설정과 고정 앱·배치는 유지됩니다.
