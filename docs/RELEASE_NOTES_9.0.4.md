# One TaskBar 9.0.4

- 라이트 모드에 기존 패널 디자인을 적용하고 더 어두운 다크 모드를 추가했습니다.
- 삼성 성능 모드의 선택 아이콘과 밝은 화면 위 알림의 대비를 수정했습니다.
- 듀오 상태 아이콘에 배터리 잔량과 충전 애니메이션을 추가했습니다.
- 좌우 독의 상태 영역을 줄이고 미디어 플레이어를 위쪽에 배치했습니다. 가로 배터리는 기존 두께를 유지합니다.
- 밝기·음량 수치 표시 옵션을 추가했습니다. 기본값은 꺼짐입니다.
- YouTube 썸네일 조회와 다중 모니터의 전체화면 감지를 수정했습니다.
