# One TaskBar 9.5.7.2

- 앱 창이 미디어 알약으로 들어가고 나오는 움직임을 참고 영상에 맞췄습니다. 원근 기울기와 배경 흐림이 더해지고, 스프링 곡선으로 약 0.4초에 끝나며, 도중에 방향을 바꿔도 끊기지 않습니다.
- 창이 알약으로 들어갈 때 미리 만든 판을 알약 위치가 조금 바뀌어도 그대로 쓰도록 해, 창이 사라졌다가 중간에서 나타나던 점프를 줄였습니다.
- 리퀴드 글래스에 가장자리 빛 번짐과 반사광을 더해 유리 같은 두께감을 냈습니다. 굴절(왜곡)은 Windows 합성기가 지원하지 않아 넣지 못했습니다.
- 펼친 전체화면 미디어는 패널 없이 커버 위에 제목과 아티스트가 크게 표시되고, 출력·재생 막대·컨트롤이 아래에 놓입니다.
- 작업표시줄을 좌우로 옮겨도 바탕화면 위젯이 겹치지 않습니다.
- 시작 화면에서 제목이 긴 앱이 위로 튀어나오지 않고, 사용자 이름 대신 Microsoft 계정 표시 이름이 보입니다. 휴대폰 배경화면 해상도도 높였습니다.
- 숨겨진 아이콘의 작은 아이콘 가장자리를 매끄럽게 다시 그립니다.
- ShareX 같은 캡처 도구의 선택 화면이 전체화면 앱으로 인식돼 독이 숨겨지던 문제를 고쳤습니다. 캡처할 때 독이 함께 찍힙니다.
- 검색 위젯과 검색 창에서 입력한 내용을 기본 브라우저로 웹 검색하거나 주소로 열 수 있습니다.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
