# One TaskBar 9.5.1

- 전체화면 미디어를 접으면 썸네일·곡 제목·재생/다음 버튼이 있는 알약형 플레이어로 바뀝니다. 재생 중에는 아래쪽에 웨이브가 표시됩니다.
- 펼친 전체화면 플레이어의 컨트롤을 빠른 설정·미디어 플레이어와 통일했습니다. 썸네일이 중복되는 문제를 수정하고, 접힌 화면에는 Windows 배경화면을 표시합니다.
- 설정에서 독과 시작 패널의 색상·불투명도·블러를 각각 조절할 수 있습니다.
- 미디어 갱신마다 전환 애니메이션을 다시 시작하지 않도록 하고, 접힌 플레이어의 불필요한 재생 시간 갱신을 줄였습니다.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
