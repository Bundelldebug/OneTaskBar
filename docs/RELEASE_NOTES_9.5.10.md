# One TaskBar 9.5.10

- 설정 창을 One UI 스타일의 좌우 2분할 구성으로 다시 만들었습니다. 왼쪽에서 항목을 고르고 검색하면 오른쪽에 해당 설정이 열리며, 옵션은 기능별로 다시 묶었습니다.
- **데스크톱 스타일**을 추가했습니다. Windows(기본 하단 작업표시줄), Mac(Dynamic Island + 하단바, 리퀴드 글래스·배경 블러·듀오 아이콘 켜짐, 하단 나우바 꺼짐), GoogleBook(상단 안드로이드 바) 중에서 고릅니다. 다른 스타일로 바꾸면 듀오 아이콘은 꺼집니다.
- Dynamic Island에 검은 띠가 있을 때 상단 오른쪽 상태 아이콘이 듀오 아이콘으로 바뀝니다.
- 배경화면과 잠금화면을 한 쌍으로 저장해 두었다가 다시 적용하는 프리셋을 추가했습니다.
- 충전 애니메이션, 창과 나우바·Island 사이 전환 애니메이션, Island·검색 화면, 리퀴드 글래스 표현을 다듬었습니다.
- 미디어 칩 팝업이 칩 위치에 맞춰 열립니다(이슈 14).
- Wallpaper Engine 배경을 위젯 블러에서 인식합니다.
- 전체화면 게임에서 Win 키·Alt+Tab 처리와 작업표시줄이 남아 보이는 문제를 손봤습니다.
- 설정에 **관리자 권한으로 실행** 옵션을 추가했습니다. 관리자 권한 게임에서도 Win 키와 Alt+Tab을 받을 수 있습니다. 다만 Windows가 관리자 권한 앱의 알림 연결을 허용하지 않아, 이 모드에서는 알림 연결을 쓸 수 없습니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
