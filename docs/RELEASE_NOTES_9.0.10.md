# One TaskBar 9.0.10

- 시작 버튼을 다시 눌러도 메뉴가 닫히지 않던 문제를 수정했습니다.
- 트레이 열기를 보완하고, 열린 트레이를 닫거나 앱을 종료할 때 발생하던 오류를 수정했습니다.
- 설정 → 데스크톱에 ‘최대화 창을 작업표시줄 뒤까지 확장’을 추가했습니다.
- Steam 게임 바로가기의 아이콘과 Chrome 프로필별 아이콘을 수정했습니다.
- 앱 화면 우클릭에 새 폴더 만들기를 추가했습니다. 설정 → 시작과 검색에서 Windows 시작 메뉴 폴더로 정리할 수도 있습니다.
- 음량·출력 기기·밝기의 반복 조회와 미디어의 중복 그리기를 줄였습니다. 재생 애니메이션과 화면 효과는 유지합니다.

UI 8.5와 9.0을 제공합니다. 설치는 `OneTaskBar-Setup.exe`, 무설치는 포터블 ZIP을 사용하세요.

배터리 사용 시간의 개선 폭은 아직 확인하지 못했습니다. 미서명 빌드이므로 Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
