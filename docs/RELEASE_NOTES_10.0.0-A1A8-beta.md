# One TaskBar 10.0.0 A1A8 Beta

- 상단바(GoogleBook)에서 바 색이 밝으면 배터리 아이콘이 밝은 색으로 바뀌고, 아래 창 색이 바뀌면 바 색이 위에서 아래로 채워지며 바뀝니다. 색은 0.06초마다 다시 읽습니다.
- 화면 설정의 야간 모드 버튼을 빠른 설정의 기능 토글 옵션으로 옮겼습니다. 기본은 꺼짐이고 토글 편집에서 추가합니다.
- 독 시계에 안 읽은 알림 개수가 표시됩니다. 알림 설정에서 끌 수 있습니다.
- 9.5 이상 UI에서 카드 윗면에 빛이 들고 아랫면이 살짝 어두워지는 입체감을 줬습니다.
- 9.5 이상 UI에서 버튼이 눌리면 줄었다가 돌아오고, 패널이 열릴 때 줄이 차례로 올라오며 나타납니다. 열림, 알림 묶음 펼침 모션은 One UI 9.5 영상처럼 시작이 빠르고 튕김이 없는 곡선으로 바꿨습니다.
베타 버전입니다. 서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
