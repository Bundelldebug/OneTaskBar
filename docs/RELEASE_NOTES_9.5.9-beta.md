# One TaskBar 9.5.9 베타

- 전체화면 미디어 화면을 추가했습니다. 썸네일을 눌러 커버 크기를 바꾸거나 별도 버튼으로 PC를 잠글 수 있습니다.
- 재생 앱을 최소화하거나 복원할 때 미디어 캡슐로 이어지는 전환 효과를 추가했습니다. 설정에서 켤 수 있습니다.
- 세로 작업표시줄에 검은 미디어 캡슐을 사용할 수 있습니다.
- 밝은 배경과 어두운 배경에 맞춰 패널의 글자와 아이콘 색을 조절합니다.
- 설정에서 뒤로 갈 때 화면이 겹치는 문제를 수정했습니다.
- 상태 영역에 추가할 수 있는 ‘바탕화면 보기’ 버튼을 추가했습니다.
- Windows 사용자 폴더 경로를 읽지 못할 때 설치가 중단되는 문제를 수정했습니다.

일반 나우바와 빠른 설정에서는 썸네일을 누르면 재생 앱이 열립니다. 커버 크기 전환은 전체화면 미디어 화면에서만 지원합니다.

전체화면 미디어 화면은 Windows 잠금화면을 대체하지 않습니다. PC 잠금 버튼을 누르면 Windows에서 실제로 잠깁니다.

이 빌드는 코드 서명되지 않았습니다. Windows에서 실행 경고 또는 차단이 발생할 수 있습니다.
