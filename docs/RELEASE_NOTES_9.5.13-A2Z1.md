# One TaskBar 9.5.13 A2Z1

- 데스크톱 스타일에 'Dex'가 생겼습니다. 기존 GoogleBook 스타일과 합쳐졌습니다. 하단 바에는 검색·시작·앱 목록 버튼이 있고, 위쪽 상태 표시줄에는 시계·미디어·캡처·입력 언어·알림·상태 캡슐이 있습니다. 빠른 설정·알림·달력·앱 목록이 One UI 9.5 Dex처럼 열리고 닫힙니다.
- 상단 상태 표시줄이 더 이상 아래 창의 색으로 물들지 않습니다. 충전을 시작하면 상단바의 배터리 표시가 그 자리에서 늘어나며 충전 애니메이션을 보여 줍니다.
- 9.5 UI의 빠른 설정 타일과 위젯 디자인을 다듬었습니다.
- 아이콘 편집기에 '사용자 이미지 그대로'가 생겼습니다. 고른 그림을 손대지 않고 그대로 쓰며, 스퀘어클 앱 아이콘을 꺼 둬도 적용됩니다. (#29)
- 모든 앱에서 앱을 오른쪽 클릭해 '모든 앱에서 숨기기'를 고를 수 있습니다. 위쪽 '숨긴 앱' 버튼을 누르면 숨긴 앱이 흐리게 보이고, 오른쪽 클릭으로 다시 표시할 수 있습니다. 검색·시작 고정·독에는 그대로 남습니다. (#29)
- 직접 만든 폴더의 아이콘이 모든 앱에서 작게 보이던 문제를 고쳤습니다. (#29)
- 노트북 배터리 사용을 줄였습니다. 화면을 읽는 횟수와 주기 작업을 줄였습니다.
서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
