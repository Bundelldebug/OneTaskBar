# One TaskBar 9.0.2

- 독과 패널의 라이트·다크 모드를 따로 선택할 수 있습니다.
- 설정 검색, 아이콘 정렬과 UI 버전 목록을 수정했습니다.
- 시작 메뉴의 바깥 클릭 닫기, 최근 파일 미리보기와 패널 시계의 달력 열기를 추가했습니다.
- 측면 독의 미디어 위치, 작업 영역 여백과 Alt+Tab 전환을 수정했습니다.
- YouTube 고화질 커버 조회를 개선했습니다. 설정에서 허용한 경우에만 현재 영상의 기록을 확인합니다.
- 투명도 설정을 제거하고 배경 투명도를 70%로 고정했습니다.

설치: `OneTaskBar-Setup.exe` · 포터블: `OneTaskBar-Portable-x64.zip`

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
