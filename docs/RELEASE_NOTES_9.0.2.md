# One TaskBar 9.0.2

UI 8.5와 9.0을 제공하는 정식 업데이트입니다. UI 9.5 유리 재질은 별도의 9.5.0 베타에 포함됩니다.

- Windows와 독립적인 One TaskBar 라이트·다크 모드와 Windows 따르기. 독과 나머지 패널의 색 모드를 따로 선택할 수 있습니다.
- 투명도 조절 항목을 제거하고 기본 배경 투명도를 70%로 고정했습니다. 이전 투명도 값에 관계없이 적용하며 다른 설정은 유지합니다. 글자가 있는 부분에는 가독성을 위한 바탕을 유지합니다.
- 연결된 Wi-Fi·Bluetooth, 음소거 및 버즈 아이콘의 대비와 개별 버튼의 원형 배경을 통일했습니다. UI 버전은 펼침 목록에서 선택합니다.
- Win 키로 연 시작 메뉴도 바깥 클릭으로 닫히며, 메뉴 내부 클릭과 끌기 동작은 유지합니다.
- 고화질 커버 설정을 켠 경우 일반 미디어 카드에도 현재 영상의 고화질 커버를 적용하고, 늦게 기록되는 영상은 제한된 횟수로 재시도합니다. 정확히 일치하는 현재 영상의 로컬 기록만 조회하며 제목은 외부로 보내지 않습니다.
- One UI 스타일의 설정 홈·카테고리·검색, 빈 검색 결과와 아이콘 정렬 수정, 통일된 선택 색상과 버튼, 상단 영역 창 이동.
- 독의 위·아래·왼쪽·오른쪽 배치와 사용자 색상·이미지 배경. 옮긴 후 남던 기본 작업표시줄 하단 여백을 반환하고 종료할 때 Windows 상태를 복원합니다.
- 고정되지 않은 실행 앱이 있을 때만 독 구분선을 표시하고, 원래 앱 아이콘에 덧씌우던 바탕을 제거했습니다.
- 시작 최근 항목의 실제 사진 미리보기와 Windows에 저장된 문서·영상 썸네일. 썸네일이 없는 항목은 원래 파일 아이콘으로 표시합니다.
- 알림에서 빠른 설정으로 돌아가기, 패널 시간 클릭으로 달력 열기, 시작·검색 입력 모양 통일, 부드러운 스크롤 경계.
- 앱 미리 보기 상단 축소와 Alt+Tab의 활성 창·소유 모달 창 전환 보강. 삼성 브라우저의 캡션 없는 전체화면에 한정해 네이티브 프레임을 보정하고 일반 창으로 돌아오면 복원합니다.

- 고투명도에서 글자가 있는 표면을 보호하고 글자 번짐 효과를 제거했습니다. 스크롤의 중복 그리기를 제거하고 UI 버전의 실제 문구 표시를 수정했습니다.
- 좌우 독의 미디어 플레이어를 같은 가장자리의 원형 커버로 배치하고 화면 안쪽으로 펼칩니다. 삼성 브라우저의 기록 잠금 상태에서도 안정된 현재 제목만 읽어 고화질 커버를 가져옵니다.

기존 고정 앱과 레이아웃을 보존합니다. Windows 숨겨진 아이콘 트레이는 기본 동작을 유지합니다.

**미서명 배포:** 사용할 수 있는 코드 서명 인증서가 없습니다. Windows가 실행을 차단할 수 있습니다. 보안 설정을 끄거나 예외를 추가하지 않으며, 배포 파일은 정상 실행·설치와 Defender 검사를 거칩니다. 전체 RAM 150 MiB 미만 목표는 아직 달성하지 못했습니다.
