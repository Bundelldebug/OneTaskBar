# One TaskBar 10.0.0 A1A7 Beta

Fluid UI를 포함한 베타입니다. 9.5.13 A1Z6의 수정 사항을 함께 적용했습니다.

- 브라우저 전체화면에서 독이 남는 문제와 시작할 때 ‘Hidden Window’ 창이 반복해서 나타나던 문제를 고쳤습니다. (#20, #24)
- Windows 야간 모드 바로가기, GoogleBook 충전 효과와 최대화 창에 맞춘 상단 안전 영역을 추가했습니다. (#21, #22)
- 세로 독 시계의 잘림을 고치고 작은 시계·날씨 위젯과 달력의 주말·한국 공휴일 표시를 추가했습니다. (#23)
- 제목 스크롤의 끊김과 상단 상태 표시의 불필요한 갱신을 줄였습니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
