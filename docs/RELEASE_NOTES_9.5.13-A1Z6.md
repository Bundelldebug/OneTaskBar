# One TaskBar 9.5.13 A1Z6

- ‘최대화 창 뒤에 작업표시줄 표시’를 켜도 브라우저 전체화면에서는 독이 숨겨집니다. 일반 최대화에서는 계속 표시됩니다. (#20)
- 설정의 디스플레이 항목에 Windows 야간 모드 바로가기를 추가했습니다. (#21)
- GoogleBook 스타일의 충전 애니메이션을 다듬고, 상단 안전 영역이 바로 아래 최대화 창의 색을 따르도록 했습니다. (#22)
- 세로 독의 시계가 잘리는 문제를 고쳤습니다. 작은 시계·날씨 위젯 크기를 추가하고 달력의 주말과 한국 공휴일을 구분했습니다. (#23)
- 시작할 때 ‘Hidden Window’ 창이 반복해서 나타나던 문제를 고쳤습니다. (#24)
- 제목 스크롤의 끊김과 상단 상태 표시의 불필요한 갱신을 줄였습니다.

서명되지 않은 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
