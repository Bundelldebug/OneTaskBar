# One TaskBar 9.0.9

알림 밀기 삭제와 사용자 알림음, 부드러운 재생바를 추가하고 삼성 노트의 Alt+Tab 전환을 수정했습니다. UI 8.5·9.0을 제공하며 기존 설정·고정 앱·배치를 유지합니다.

- 알림 캡슐을 좌우로 밀면 이동·사라짐 애니메이션과 함께 삭제됩니다. 짧게 밀면 제자리로 돌아오고 세로 스크롤은 유지됩니다. 접힌 묶음은 전체 묶음, 펼친 카드는 해당 알림만 삭제합니다. 캡슐의 X를 제거했으며 우클릭과 Delete 키도 사용할 수 있습니다.
- 검색 추천 앱을 최근 사용 기준 최대 12개까지 표시합니다.
- 9.0 미디어 플레이어의 재생 웨이브를 부드러운 곡선으로 바꿨습니다. 일시정지하면 웨이브가 자연스럽게 낮아져 사라지고, 빠르게 다시 재생해도 이어서 움직입니다.
- 데스크톱 전환창을 다시 열 때 창 틀을 재사용하고 썸네일 배치 갱신을 줄였습니다. 창 목록 조회는 UI 스레드 밖에서 수행하고, 멈췄거나 숨겨진 웨이브·긴 제목의 애니메이션 콜백은 해제합니다.
- 삼성 노트의 내부 창과 호스트 프레임을 구분해 응답 확인·현재 창 선택·활성화를 처리합니다. 거절된 선택적 입력 큐 연결 때문에 전체 전환을 중단하지 않도록 했습니다. 개발 PC에서 노트로 들어가고 나오는 실제 Alt+Tab을 확인했습니다.
- 설정 → 패널 선택 → 사용자 알림음에서 로컬 소리 파일을 선택·미리 듣기·지울 수 있습니다. 기본값은 꺼짐이며 충전 연결음과 별개입니다. 알림 내역이나 중복 항목에는 재생하지 않습니다. Windows 자체 알림음 설정은 변경하지 않습니다.
- [이슈 #5](https://github.com/Bundelldebug/OneTaskBar/issues/5)의 트레이 아이콘 색상 문제를 수정했습니다. 흑백 로고의 원래 명암과 팝업 글자색을 보존합니다.

미디어·시작·검색·알림·창 전환·설정·자원 정리의 격리 회귀 검사를 사용합니다. 미서명 설치 파일과 포터블에는 체크섬과 CI 출처 기록을 함께 제공합니다. 전체 RAM 150MB 미만 목표는 아직 달성하지 못했으며, 실제 배터리 수명 개선량을 측정한 것은 아닙니다.

**미서명 배포:** Windows SmartScreen 또는 조직 보안 정책에 따라 추가 확인이나 실행 차단이 발생할 수 있습니다. Defender 검사 통과는 코드 서명을 대신하지 않습니다. 보안 정책이나 백신 예외는 변경하지 않습니다.
