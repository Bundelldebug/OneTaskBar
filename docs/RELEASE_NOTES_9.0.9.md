# One TaskBar 9.0.9

- 알림을 좌우로 밀어서 삭제할 수 있습니다. 짧게 밀면 원래 자리로 돌아옵니다.
- 검색 추천 앱을 최대 12개로 늘렸습니다.
- 재생바의 웨이브 곡선과 일시정지 애니메이션을 다듬었습니다.
- 데스크톱 전환창의 재호출 지연과 삼성 노트의 Alt+Tab 전환을 수정했습니다.
- 설정 → 패널 선택에서 사용자 알림음을 지정할 수 있습니다.
- 트레이에서 흑백 앱 아이콘의 색이 잘못 표시되던 문제를 수정했습니다.
