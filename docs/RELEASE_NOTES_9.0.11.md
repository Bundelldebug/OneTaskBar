# One TaskBar 9.0.11

- 설정 → 데스크톱에서 작업표시줄을 표시할 모니터를 고를 수 있습니다. 모든 모니터, 주 모니터, 지정 모니터를 지원합니다. 지정한 화면을 분리하면 주 모니터로 돌아옵니다. (#8)
- 설정 → 화면 → 상태 영역 바로가기에서 터치 키보드와 캐스트 버튼을 추가할 수 있습니다.
- 출력 기기를 바꾼 뒤 음소거 상태가 실제 소리와 다르게 표시되는 문제를 수정했습니다.
- 데스크톱 전환 화면의 열기·닫기 애니메이션을 다듬었습니다. 트랙패드 연동은 제거했으며, 독 버튼과 Win+Tab의 전환 화면 선택은 유지합니다.

UI 8.5와 9.0을 제공합니다. 설치는 `OneTaskBar-Setup.exe`, 무설치는 포터블 ZIP을 사용하세요.

미서명 빌드입니다. Windows SmartScreen이나 조직 정책에 따라 실행이 차단될 수 있습니다.
